DeskPort 是什麼

  1. DeskPort 把一台電腦共享出來，讓你的其他裝置使用它的桌面。
  2. 被使用的電腦是主機，你面前操作的裝置是用戶端。一台電腦可以同時是兩者。
  3. 裝置之間只需綁定一次。存取權限在主機上核准，也可以在主機上收回。
  4. DeskPort 將已儲存的裝置和設定保存在本機，無需註冊 DeskPort 帳號。

共享這台電腦

  1. 點頂欄的共享，選擇開始共享。
  2. 依提示授予螢幕錄製和輔助使用權限。不授予也能啟動共享，但畫面或輸入無法運作。
  3. 共享圖示下方有圓點，表示這台電腦正在被共享。
  4. 在 macOS 上，如果畫面空白或無法遠端控制，請檢查系統設定中的螢幕錄製和輔助使用權限。「共享」頁面會顯示權限與連線就緒檢查。
  5. 隱藏 DeskPort 視窗後仍可在背景共享。如果不希望這台電腦繼續接受桌面連線，請選擇「停止共享」。

連線到電腦

  1. 同一網路裡的裝置會自己出現在裝置清單上。
  2. 不同網路的電腦，用新增卡片上的新增裝置，輸入它的位址。
  3. 第一次選擇某台裝置時會向主機申請存取，在主機上核准即可。
  4. 如果已經有其他裝置在連線，會詢問是否接管。接管會中斷那台裝置。
  5. 跨網路連線時，兩台裝置仍須透過自己的 VPN 或 Tailscale 等網路互相存取。新增位址本身不會建立網路通道。
  6. 裝置卡片選單中的「變更地址」可填寫多個位址，每行一個，皆使用配對時的連接埠。DeskPort 會同時嘗試這些位址，並使用清單中最前面且能連通的那個，因此可將區域網路位址放在第一行，網域名稱或 VPN 位址放在後面。連線期間也可以修改：已開啟的連線繼續使用目前位址，下次連線時使用新的清單。
  7. Sunshine 等不支援 DeskPort 綁定的主機可以使用「新增舊版主機」和 PIN 配對。請保持主機程式開啟，以便確認 PIN。
  8. 要撤銷控制權限，請在提供共享的電腦上移除已儲存的存取授權。移除裝置卡片與撤銷授權是兩項操作；解除兩台電腦的雙向綁定時，請分別移除兩端授權。

整理裝置清單

  1. 頂欄的編輯進入編輯模式，拖動卡片可以排序。
  2. 把一台裝置拖到另一台上就會成組，和手機桌面的資料夾一樣。
  3. 卡片選單裡的設定別名只在本機生效。
  4. 重新整理會重新檢查已儲存的裝置，並探測新裝置。
  5. 開啟裝置卡片選單可查看狀態、位址和連線操作。「變更位址」會更新儲存的連線入口；設定別名不會改變遠端電腦的名稱。

視窗與背景連線

  1. 在電腦端，關閉或隱藏遠端視窗後，連線仍保留在背景。「中斷連線」會結束該連線；「結束」會關閉 DeskPort。
  2. 可以從系統匣選單或裝置列表喚回已連線的桌面。有多個連線時，從工作階段選單選擇要使用的桌面。
  3. 隱藏遠端視窗或切換焦點時，會釋放遠端按住的按鍵和滑鼠按鈕。遠端連線保留期間，本機仍可正常使用。
  4. 如果工作階段需要重新建立連線，或要套用已儲存的串流設定，請在裝置選單中使用「重新連線」。

電腦端鍵盤快捷鍵

  1. Meta + ' 可顯示或隱藏 DeskPort：macOS 使用 Command + '，Windows 使用 Windows + '，Linux 使用 Super + '。放開組合鍵後觸發；有連線時喚回所選工作階段，沒有連線時顯示裝置列表。
  2. 「設定 → 鍵盤快速鍵 → 全域視窗快速鍵」預設開啟。關閉後立即釋放系統快速鍵，並停用遠端視窗內的備用處理。此選項保存在本機。
  3. 在設定 → 鍵盤快速鍵中，點選「全域視窗快速鍵」同一行的目前組合鍵。按下組合鍵或使用「選擇按鍵」，然後儲存。新綁定立即在目前電腦生效。回復預設會回到 Meta + 單引號（macOS 為 Command + 單引號）。取消會保留原綁定。錄入期間全域快速鍵暫停。
  4. KDE Plasma 通常將 Meta+1–9 指派給工作管理員項目。如果錄入沒有反應，可用「選擇按鍵」輸入組合鍵。儲存時，桌面環境可能要求你解決快速鍵衝突；也可以選擇其他組合鍵。
  5. 在 Wayland 上，桌面環境可能請求授權並讓你選擇快速鍵，以桌面指派的組合鍵為準。如果授權被拒絕、不受支援或快速鍵已被占用，可使用系統匣或裝置列表；DeskPort 不會替換其他應用程式的快速鍵。
  6. 電腦端連線期間，Ctrl+Alt+Shift+Z 釋放或重新擷取遠端輸入，X 切換全螢幕，N 切換到下一個已連線桌面。每個字母都需同時按住 Ctrl+Alt+Shift。
  7. Ctrl+Alt+Shift+S 顯示或隱藏串流統計；D 最小化遠端視窗；M 切換指標模式；C 在桌面指標模式下切換本機指標顯示；L 切換指標範圍鎖定。
  8. Ctrl+Alt+Shift+V 將本機剪貼簿文字作為輸入文字傳送。Q 會先離開全螢幕；在視窗模式下再按 Ctrl+Alt+Shift+Q 則中斷連線。

全螢幕

  1. 在電腦端，「裝置設定 → 進階串流設定 → 連線視窗」可選擇下次連線時使用視窗、全螢幕或無邊框全螢幕。
  2. 在電腦上，連線過程中按 Ctrl+Alt+Shift+X 可以切換全螢幕；在手機或平板上，它會讓懸浮按鈕回到螢幕上。
  3. 手機和平板上，遠端桌面一律佔滿整個螢幕。點一下懸浮按鈕開啟鍵盤，按住它開啟選單。
  4. 主機可以請求已連線的裝置退出全螢幕，但不會強制它進入全螢幕。

畫質與虛擬螢幕

  1. 遠端桌面跟隨你的視窗大小，改變視窗尺寸就會調整遠端桌面。
  2. 虛擬螢幕決定連線期間主機自己的螢幕如何處理。
  3. 桌面微調讓遠端桌面上的內容整體變大或變小。
  4. 這些設定按裝置分別儲存。
  5. 「符合視窗」按遠端視窗的實際繪製像素匹配桌面尺寸。關閉後使用儲存的解析度；可用桌面尺寸和縮放仍取決於主機能力。
  6. 桌面微調：1.5 讓控制項更大，0.5 容納更多內容，連線期間可立即生效。主機的最小桌面尺寸可能限制進一步放大，可嘗試增大視窗或全螢幕。
  7. 「主螢幕 + 鏡像」鏡像遠端工作區，「僅主螢幕」關閉主機的其他螢幕，「延伸」增加工作區。具體支援取決於主機；工作階段結束後恢復原螢幕配置。

鍵盤、指標與剪貼簿

  1. 「裝置設定 → 輸入」控制是否傳送鍵盤、指標和控制器操作。僅觀看時可關閉；「聲音」單獨控制是否接收音訊。
  2. 「進階串流設定 → 鍵盤與指標」包含指標模式、捲動方向、系統快速鍵轉送和工作階段剪貼簿共享。
  3. 連線 Mac 主機時，Super / Windows 對應 Command，Alt 對應 Option。作業系統可能保留部分快速鍵；可用 Ctrl+Alt+Shift+Z 將輸入交還本機。
  4. 「使用本機輸入法」預設關閉。可按裝置開啟並重新連線，使用本機輸入法組字。候選視窗靠近左上角，而非遠端游標位置；遊戲等情境可改用遠端輸入法或實體按鍵模式。
  5. 雙方都支援時，工作階段剪貼簿可共享文字、圖片和檔案。如果複製貼上失敗，請保持連線，並檢查兩端的共享選項。
  6. 多數裝置串流設定需重新連線後生效；桌面微調可在工作階段期間生效，外觀和全域視窗快速鍵則立即生效。

畫質、聲音與流量

  1. 「進階串流設定」提供自動、清晰、流暢、節省流量和自訂畫面模式。自動模式根據解析度選擇頻寬，並隨網路狀況調整。
  2. 節省流量模式使用 30 fps，並將視訊限制為 5 Mbps。頂端列的節省流量開關作用於所有裝置；音訊和協定流量另計。
  3. 更高的影格率和頻寬需要更多網路與處理能力。如果畫面卡頓或操作延遲，請先降低這些設定並查看串流統計，再逐步提高畫質。
  4. 聲音選項包括 DeskPort 失去焦點時靜音，以及同時在主機播放。如果沒有聲音，請檢查裝置的聲音開關、失焦靜音和兩台電腦的音訊輸出。

從瀏覽器連線

  1. 在電腦主機開啟「共享 → 瀏覽器存取」，然後在另一台裝置掃描或開啟顯示的網址。連線前請先啟動共享。
  2. 輸入主機或驗證器應用程式顯示的六位驗證碼，驗證碼每 30 秒更新一次。被識別為登入同一 Tailscale 帳號的裝置可以免驗證碼連線。
  3. 連線裝置需要信任主機的本機 HTTPS 憑證。信任前，請核對網址與憑證確實屬於自己的主機。
  4. 選擇「記住此瀏覽器 7 天」可在該瀏覽器後續存取時免輸驗證碼。可在「共享」中移除已配對瀏覽器來撤銷授權。請勿公開驗證器 QR 碼；重設密鑰會使原有驗證器失效。

設定、隱私與意見回饋

  1. 「設定」控制本機主題、強調色、語言、頂端列流量顯示和全域視窗快速鍵；「裝置設定」則分別控制各個已儲存的連線。
  2. 診斷記錄預設關閉。重現問題前，可在「設定 → 診斷與意見回饋」中開啟。記錄保存在本機，由你決定是否分享。
  3. 「回報問題」會產生 ZIP 並開啟 GitHub 問題草稿，不會自動上傳或提交。請先檢查壓縮檔，再描述重現步驟、作業系統和預期行為，然後自行附到公開問題中。
  4. 關閉診斷只會停止新增記錄。「清除已儲存的診斷」會刪除現有記錄和產生的 ZIP。設定中的「隱私」和「授權條款」說明了記錄內容與內含軟體。

出問題怎麼辦

  1. 顯示離線的裝置，通常是睡眠了、在另一個網路，或者沒有開啟共享。
  2. 頂欄的重新整理會重新檢查每一台已儲存的裝置。
  3. 設定裡的回報問題會產生記錄壓縮檔，可以附在 issue 上。發出前請先檢查內容。
  4. 裝置持續離線時，請確認其已喚醒、共享已開啟且儲存的位址可存取。重試前檢查主機就緒狀態和防火牆；重新整理不能喚醒所有主機，也不能修復網路路由。
  5. 黑畫面時請檢查螢幕錄製權限和主機所選顯示器。無法控制時，請檢查輔助使用權限、裝置的輸入開關以及遠端視窗是否取得焦點。
  6. 全域視窗快速鍵無效時，請檢查設定開關、桌面快速鍵授權及其他應用程式的衝突。可關閉再開啟以重新註冊；仍可使用系統匣和裝置列表。
