DeskPort 是什么

  1. DeskPort 把一台电脑共享出来，让你的其他设备使用它的桌面。
  2. 被使用的电脑是主机，你面前操作的设备是客户端。一台电脑可以同时是两者。
  3. 设备之间只需绑定一次。访问权限在主机上批准，也可以在主机上收回。
  4. DeskPort 将已保存的设备和设置保存在本机，无需注册 DeskPort 账号。

共享这台电脑

  1. 点顶栏的共享，选择开始共享。
  2. 按提示授予屏幕录制和辅助功能权限。不授予也能启动共享，但画面或输入无法工作。
  3. 共享图标下面有圆点，表示这台电脑正在被共享。
  4. 在 macOS 上，如果画面空白或无法远程控制，请检查系统设置中的屏幕录制和辅助功能权限。“共享”页面会显示权限与连接就绪检查。
  5. 隐藏 DeskPort 窗口后仍可在后台共享。如果不希望这台电脑继续接受桌面连接，请选择“停止共享”。

连接到电脑

  1. 同一网络里的设备会自己出现在设备列表上。
  2. 不同网络的电脑，用添加卡片上的添加设备，输入它的地址。
  3. 第一次选择某台设备时会向主机申请访问，在主机上批准即可。
  4. 如果已经有其他设备在连接，会询问是否接管。接管会断开那台设备。
  5. 跨网络连接时，两台设备仍须通过自己的 VPN 或 Tailscale 等网络互相访问。添加地址本身不会建立网络通道。
  6. 设备卡片菜单中的“更改地址”可填写多个地址，每行一个，都使用配对时的端口。DeskPort 会同时尝试这些地址，并使用列表中最靠前且能连通的那个，因此可把局域网地址放在第一行，域名或 VPN 地址放在后面。连接期间也可以修改：已打开的连接继续使用当前地址，下次连接时使用新的列表。
  7. Sunshine 等不支持 DeskPort 绑定的主机可以使用“添加旧版主机”和 PIN 配对。请保持主机程序打开，以便确认 PIN。
  8. 要撤销控制权限，请在提供共享的电脑上移除已保存的访问授权。移除设备卡片与撤销授权是两项操作；解除两台电脑的双向绑定时，请分别移除两端授权。

整理设备列表

  1. 顶栏的编辑进入编辑模式，拖动卡片可以排序。
  2. 把一台设备拖到另一台上就会成组，和手机桌面的文件夹一样。
  3. 卡片菜单里的自定义名称只在本机生效。
  4. 刷新会重新检查已保存的设备，并探测新设备。
  5. 打开设备卡片菜单可查看状态、地址和连接操作。“更改地址”会更新保存的连接入口；设置别名不会改变远程电脑的名称。

窗口与后台连接

  1. 在电脑端，关闭或隐藏远程窗口后，连接仍保留在后台。“断开连接”会结束该连接；“退出”会关闭 DeskPort。
  2. 可以从托盘菜单或设备列表唤回已连接的桌面。有多个连接时，从会话菜单选择要使用的桌面。
  3. 隐藏远程窗口或切换焦点时，会释放远端按住的按键和鼠标按钮。远程连接保留期间，本机仍可正常使用。
  4. 如果会话需要重新建立连接，或要应用已保存的串流设置，请在设备菜单中使用“重新连接”。

电脑端键盘快捷键

  1. Meta + ' 可显示或隐藏 DeskPort：macOS 使用 Command + '，Windows 使用 Windows + '，Linux 使用 Super + '。松开组合键后触发；有连接时唤回所选会话，没有连接时显示设备列表。
  2. “设置 → 键盘快捷键 → 全局窗口快捷键”默认开启。关闭后立即释放系统快捷键，并停用远程窗口内的备用处理。此选项保存在本机。
  3. 在设置 → 键盘快捷键中，点击“全局窗口快捷键”同一行的当前组合键。按下组合键或使用“选择按键”，然后保存。新绑定立即在当前电脑生效。恢复默认会回到 Meta + 单引号（macOS 为 Command + 单引号）。取消会保留原绑定。录入期间全局快捷键暂停。
  4. KDE Plasma 通常将 Meta+1–9 分配给任务管理器条目。如果录入没有反应，可用“选择按键”输入组合键。保存时，桌面环境可能要求你解决快捷键冲突；也可以选择其他组合键。
  5. 在 Wayland 上，桌面环境可能请求授权并让你选择快捷键，以桌面分配的组合键为准。如果授权被拒绝、不受支持或快捷键已被占用，可使用托盘或设备列表；DeskPort 不会替换其他应用的快捷键。
  6. 电脑端连接期间，Ctrl+Alt+Shift+Z 释放或重新捕获远程输入，X 切换全屏，N 切换到下一个已连接桌面。每个字母都需同时按住 Ctrl+Alt+Shift。
  7. Ctrl+Alt+Shift+S 显示或隐藏串流统计；D 最小化远程窗口；M 切换指针模式；C 在桌面指针模式下切换本地指针显示；L 切换指针范围锁定。
  8. Ctrl+Alt+Shift+V 将本地剪贴板文本作为输入文字发送。Q 会先退出全屏；在窗口模式下再按 Ctrl+Alt+Shift+Q 则断开连接。

全屏

  1. 在电脑端，“设备设置 → 高级串流设置 → 连接窗口”可选择下次连接时使用窗口、全屏或无边框全屏。
  2. 在电脑上，连接过程中按 Ctrl+Alt+Shift+X 可以切换全屏；在手机或平板上，它会让悬浮按钮回到屏幕上。
  3. 手机和平板上，远程桌面始终占满整个屏幕。点按悬浮按钮打开键盘，按住它打开菜单。
  4. 主机可以请求已连接的设备退出全屏，但不会强制它进入全屏。

画质与虚拟屏

  1. 远程桌面跟随你的窗口大小，改变窗口尺寸就会调整远程桌面。
  2. 虚拟屏决定连接期间主机自己的屏幕如何处理。
  3. 桌面微调让远程桌面上的内容整体变大或变小。
  4. 这些设置按设备分别保存。
  5. “适应窗口”按远程窗口的实际绘制像素匹配桌面尺寸。关闭后使用保存的分辨率；可用桌面尺寸和缩放仍取决于主机能力。
  6. 桌面微调：1.5 让控件更大，0.5 容纳更多内容，连接期间可立即生效。主机的最小桌面尺寸可能限制进一步放大，可尝试增大窗口或全屏。
  7. “主屏幕 + 镜像”镜像远程工作区，“仅主屏幕”关闭主机的其他屏幕，“扩展”增加工作区。具体支持取决于主机；会话结束后恢复原屏幕布局。

键盘、指针与剪贴板

  1. “设备设置 → 输入”控制是否发送键盘、指针和手柄操作。仅观看时可关闭；“声音”单独控制是否接收音频。
  2. “高级串流设置 → 键盘与指针”包含指针模式、滚动方向、系统快捷键转发和会话剪贴板共享。
  3. 连接 Mac 主机时，Super / Windows 对应 Command，Alt 对应 Option。操作系统可能保留部分快捷键；可用 Ctrl+Alt+Shift+Z 将输入交还本机。
  4. “使用本地输入法”默认关闭。可按设备开启并重新连接，使用本机输入法组字。候选窗口靠近左上角，而非远程光标位置；游戏等场景可改用远程输入法或物理按键模式。
  5. 双方都支持时，会话剪贴板可共享文本、图片和文件。如果复制粘贴失败，请保持连接，并检查两端的共享选项。
  6. 多数设备串流设置需重新连接后生效；桌面微调可在会话期间生效，外观和全局窗口快捷键则立即生效。

画质、声音与流量

  1. “高级串流设置”提供自动、清晰、流畅、省流量和自定义画面模式。自动模式根据分辨率选择带宽，并随网络状况调整。
  2. 省流量模式使用 30 fps，并将视频限制为 5 Mbps。顶栏的省流量开关作用于所有设备；音频和协议流量另计。
  3. 更高的帧率和带宽需要更多网络与处理能力。如果画面卡顿或操作延迟，请先降低这些设置并查看串流统计，再逐步提高画质。
  4. 声音选项包括 DeskPort 失去焦点时静音，以及同时在主机播放。如果没有声音，请检查设备的声音开关、失焦静音和两台电脑的音频输出。

从浏览器连接

  1. 在电脑主机打开“共享 → 浏览器访问”，然后在另一台设备扫描或打开显示的网址。连接前请先启动共享。
  2. 输入主机或身份验证器应用显示的六位验证码，验证码每 30 秒更新一次。被识别为登录同一 Tailscale 账号的设备可以免验证码连接。
  3. 连接设备需要信任主机的本地 HTTPS 证书。信任前，请核对网址与证书确实属于自己的主机。
  4. 选择“记住此浏览器 7 天”可在该浏览器后续访问时免输验证码。可在“共享”中移除已配对浏览器来撤销授权。请勿公开身份验证器二维码；重置密钥会使原有身份验证器失效。

设置、隐私与反馈

  1. “设置”控制本机主题、强调色、语言、顶栏流量显示和全局窗口快捷键；“设备设置”则分别控制各个已保存的连接。
  2. 诊断日志默认关闭。复现问题前，可在“设置 → 诊断与反馈”中开启。日志保存在本机，由你决定是否分享。
  3. “报告问题”会生成 ZIP 并打开 GitHub 问题草稿，不会自动上传或提交。请先检查压缩包，再描述复现步骤、操作系统和预期行为，然后自行附到公开问题中。
  4. 关闭诊断只会停止新增记录。“清除已保存的诊断”会删除现有日志和生成的 ZIP。设置中的“隐私”和“许可证”说明了记录内容与内含软件。

出问题怎么办

  1. 显示离线的设备，通常是睡眠了、在另一个网络，或者没有开启共享。
  2. 顶栏的刷新会重新检查每一台已保存的设备。
  3. 设置里的报告问题会生成日志压缩包，可以附在 issue 上。发出前请先检查内容。
  4. 设备持续离线时，请确认其已唤醒、共享已开启且保存的地址可访问。重试前检查主机就绪状态和防火墙；刷新不能唤醒所有主机，也不能修复网络路由。
  5. 黑屏时请检查屏幕录制权限和主机所选显示器。无法控制时，请检查辅助功能权限、设备的输入开关以及远程窗口是否获得焦点。
  6. 全局窗口快捷键无效时，请检查设置开关、桌面快捷键授权及其他应用的冲突。可关闭再开启以重新注册；仍可使用托盘和设备列表。
