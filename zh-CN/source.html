版本说明

构建 14 将已签名的 SDK 修正重新打包为 1.5 版，用于 TestFlight 和 App Store 审核。

构建 13（1.3 版）对从源码构建的 OpenSSL XCFramework 进行签名，并在归档时校验 SDK 来源的签名元数据。App Store 处理和审核另行进行。

构建 11 包含自适应设备卡片、连接和输入改进，以及从源码构建的 OpenSSL 及对应调试符号。其完整源码下载托管在链接的纯源码 GitHub release 中；App Store 审核状态另行处理。

构建 7 将构建 6 重新打包为 1.1 版用于 App Store 发布，应用行为没有变化。

构建 6 新增直接进入桌面、按设备调整桌面，以及经确认的会话接管，并在被替换的客户端上显示具体说明。

构建 5 新增共享工作区核心和按设备的虚拟屏幕策略，采用严格的能力协商，并让小屏设备上的设置更易读。

构建 4 过滤原版 Sunshine 服务，保留 DeskPort 批准绑定，并支持编辑已保存的域名/IP 而不移除现有绑定。发现传输方式不变。

构建 3 补充了完整的离线依赖声明，并固定了已在使用的 OpenSSL 包版本。连接界面与构建 2 相同。构建 2 移除了上游的自动公网地址发现。构建 1 的源码继续向初始 TestFlight 构建的接收者提供。

源码与许可

可免费下载对应版本的完整源码、依赖源码和构建说明。开发仓库保持私有；这里提供可独立编译的发布源码包。你可以按适用许可研究、修改和重新分发软件。安装自己编译的版本时，请使用自己的 Apple 开发签名配置。

不提供任何担保。Apple SDK 和签名凭据由构建者自行提供。DeskPort 不提供第三方媒体目录或订阅内容访问；请只使用你有权访问的电脑和内容。

源码下载问题：通过 GitHub Issues 报告。请勿发布凭据或私人内容。
