## Основные возможности

- **Одно настольное приложение для просмотра и демонстрации.** Встроенный Sunshine, одобрение устройств,
  независимые учётные данные и настройки; не нужно отдельно устанавливать Sunshine для
  хост-пакетов macOS, Windows и Linux (кроме Flatpak, который работает только как клиент просмотра).
- **Рабочее пространство, которое подстраивается под клиент.** Адаптивный размер на совместимых хостах macOS
  и KDE, HiDPI, портретная/альбомная раскладка на мобильных устройствах и настройка размера для каждого устройства.
  При изменении размера видео ненадолго переподключается; это не бесшовная смена параметров кодировщика.
- **Выбор политики дисплея хоста.** Виртуальный основной экран с зеркалированием остальных,
  виртуальный основной экран с отключением остальных или расширенное рабочее пространство на подходящих
  хостах. По завершении сеанса DeskPort восстанавливает сохранённую раскладку.
- **Переход между авторизованными устройствами.** Подтверждение перед перехватом активного
  сеанса; вытесненный клиент получает аутентифицированное объяснение перехвата.
- **Рабочий стол всегда под рукой.** Скрывайте и вызывайте подключённый клиент просмотра, освобождайте
  удалённый ввод при скрытии и отключайте просмотр независимо от локальной демонстрации.
- **Настройки для каждого компьютера.** Изображение, звук, ввод, тонкая настройка рабочего стола и редактирование
  адреса сохраняются для устройства; карточки, закрепление, темы и локализованные интерфейсы.
- **Общий буфер обмена по запросу.** Текст обновляется сразу;
  поддерживаемые изображения и файлы загружаются по запросу между связанными настольными
  устройствами, на которых это включено. См. [возможности и ограничения буфера обмена](../CLIPBOARD.md).
- **Нативное мобильное управление.** iPhone/iPad и клиент Android предлагают
  сенсорный ввод/трекпад, управление клавиатурой и прямой вход в удалённый рабочий стол.
- **Необязательный автозапуск при входе и восстановление на macOS.** Требуют активного графического
  сеанса и одобрения системы; они не разблокируют FileVault и не выполняют вход за вас.

> **Примечание об антивирусах Windows:** Антивирусы могут ошибочно помечать вспомогательные компоненты DeskPort для Windows как угрозу.
> В наших собственных тестах такого не наблюдалось. Не отключайте Defender; если появится предупреждение,
> см. отчёт о проверке выпуска и [историю образцов](../WINDOWS_DEVELOPMENT.md#windows-antivirus-notice).

Нативным пакетам Linux требуется glibc 2.39+: Ubuntu 24.04+/Debian 13+, Fedora 44,
актуальный Arch. AppImage включает собственную среду выполнения для систем со старой glibc;
возможности хоста по-прежнему зависят от драйверов оборудования и поддержки композитора. Хостингу с виртуальным дисплеем в KDE нужны
записи разрешений композитора. Нативные пакеты и Nix предоставляют фиксированные записи; сборки
AppImage и переносные сборки автоматически регистрируют текущий путь вспомогательного модуля дисплея
при запуске демонстрации. Для ввода на хосте по-прежнему нужны разрешения на устройства. Мобильные приложения
не выступают хостом рабочего стола.
Наличие определения в исходниках или успешная компиляция сами по себе не делают платформу поддерживаемой.

## Установка

**macOS:** Откройте [DMG](https://github.com/keithxc/deskport/releases/download/v0.7.3/DeskPort-0.7.3-macos-arm64.dmg),
перетащите DeskPort в «Программы» и запустите. Предоставьте разрешения «Запись экрана» и
«Универсальный доступ», чтобы использовать функции хоста. Nix и Homebrew не нужны.

**Linux:** Выберите [пакет 0.7.3](https://github.com/keithxc/deskport/releases/tag/v0.7.3)
для своей системы и следуйте [руководству по установке](../LINUX_PACKAGES.md),
включая разрешения на ввод для хоста. Через Nix: `nix run github:keithxc/deskport/v0.7.3`.
Flatpak обеспечивает только просмотр. Файлы выпуска включают [контрольные суммы SHA-256](https://github.com/keithxc/deskport/releases/download/v0.7.3/SHA256SUMS.txt) и [отчёт о проверке](https://github.com/keithxc/deskport/releases/download/v0.7.3/VERIFICATION.txt).

**Android 2.7 (63)** · Пока не завершено закрытое тестирование в Google Play, [APK](https://github.com/keithxc/deskport/releases/download/v0.7.8/DeskPort-2.7-63.apk) временно доступен на GitHub. Исходный код мобильных клиентов закрыт. Здесь распространяется только установочный пакет.

Сборка 63 подписана тем же ключом, что и приложение в Google Play. При обновлении до более новой версии из магазина сохраняются настройки и сопряжения с компьютерами. Если у вас установлена сборка 62 с GitHub, перед установкой сборки 63 её нужно удалить. Локальные настройки будут сброшены, а компьютеры придётся подключить заново.

**iPhone / iPad:** Установите [DeskPort из App Store](https://apps.apple.com/us/app/deskport/id6812389978).
Мобильное приложение — платная разовая покупка; актуальную местную цену см. в вашем магазине.
Настольные выпуски остаются бесплатными и с открытым исходным кодом. Покупки поддерживают подписание,
тестовое оборудование и дальнейшую разработку.

Запустите демонстрацию на хосте, выберите его на клиенте и одобрите устройство на
хосте. Обоим устройствам нужен работающий сетевой путь: используйте локальную сеть или собственный VPN, например
Tailscale. DeskPort не предоставляет сервис учётных записей, размещённые рабочие столы, ретранслятор
или сетевой туннель. Классическое сопряжение Sunshine по PIN-коду по-прежнему доступно.

**0.7.3 стабильная:** Обновление добавляет общий каталог интерфейса на 22 языках с переключением языка в браузере и улучшает общий доступ в сеансах Windows после входа пользователя и DPI виртуальных дисплеев, среду выполнения Linux и буфер обмена Wayland, защищённые рабочие пространства Hyprland/X11, необязательный локальный IME и квадратные карточки устройств. Изменения и границы проверок описаны в [примечаниях к выпуску 0.7.3](../releases/RELEASE_0.7.3.md).

**Объём проверок 0.7.3:** В Windows прошли точное сравнение содержимого пакетов, проверки PE и нативного CLI, а Defender не обнаружил угроз; установка, подключение через GUI и трансляция не проверялись. Итоговый AppImage прошёл проверку в виртуальной машине Bazzite с обычным FUSE и программным GPU. В виртуальной машине Ubuntu 26.04 DEB версии 0.7.2 воспроизвёл сбой VA; итоговый DEB версии 0.7.3 устранил его и прошёл обновление. Откат воспроизвёл сбой старой версии; последующее удаление сохранило синтетические тестовые настройки. Захват и восстановление GNOME ещё не приняты. Результаты контейнеров/Flatpak и остальные ограничения приведены в [отчёте о проверке](https://github.com/keithxc/deskport/releases/download/v0.7.3/VERIFICATION.txt); это не полная проверка на физическом оборудовании.

**Предыдущий выпуск: 0.7.2 стабильная:** [Настольный выпуск](https://github.com/keithxc/deskport/releases/tag/v0.7.2) объединяет улучшения изменения размера, удалённой трансляции, экономии трафика и среды выполнения Linux, а также исправляет проблемы AppImage в Bazzite/KDE Wayland. См. [примечания к выпуску 0.7.2](../releases/RELEASE_0.7.2.md); шаги установки для разных дистрибутивов Linux — в [английском README](../../README.md#linux-installation-by-distribution).

**Доступ через браузер:** Настольные хосты предоставляют удалённый рабочий стол по HTTPS с
30-секундным кодом входа, необязательным сопряжением браузера на семь дней, адаптивным размером
и полноэкранным режимом. См. [примечания к выпуску 0.7.1](../releases/RELEASE_0.7.1.md) и
[руководство по браузеру](../BROWSER_ACCESS.md). AppImage содержит собственную среду glibc;
нативные пакеты по-прежнему требуют glibc 2.39.

## Сборка и запуск в Linux

С включёнными Nix и flakes:

```sh
git clone https://github.com/keithxc/deskport.git
cd deskport
nix build
./result/bin/deskport
```

Сторонние исходные зависимости клиента просмотра включены в репозиторий (vendored); общее ядро и
входные данные сборки Nix остаются закреплёнными внешними зависимостями. Нативные сборки должны инициализировать
`shared/deskport-core`. См. [docs/VENDORED.md](../VENDORED.md).
О настройке SSH, локальном управлении хостом, требованиях к VPS и Omarchy/Hyprland
см. [руководство по CLI](../CLI.md). `deskport doctor` проверяет требования для хостинга;
`deskport status --json` проверяет запущенный экземпляр без открытия окна.
`nix run . -- --help` выводит интерфейс командной строки. Перед подключением запустите демонстрацию на хосте и свяжите устройства. Классическое
сопряжение Sunshine по PIN-коду также доступно. Никакие личные учётные данные хоста или сопряжения
не включены и не импортируются из Moonlight.
Новые адреса, введённые вручную, по умолчанию используют порт DeskPort `48989`. Укажите порт, показанный
на странице демонстрации хоста, если он отличается, или используйте `host:47989`, чтобы явно подключиться
к отдельной установке Sunshine с настройками по умолчанию. Сохранённые/обнаруженные адреса сохраняют
собственные порты.

Для редактируемой нативной сборки:

```sh
git submodule update --init shared/deskport-core
nix develop
mkdir -p build
cd build
qmake ../moonlight-qt.pro CONFIG+=disable-prebuilts
make -j4
./app/deskport
```

Имена файлов upstream-проекта не изменены, чтобы форк было удобно проверять.

## Чем отличается от Moonlight?

- Встроенный хост Sunshine с одобрением устройств, перехватом сеанса и настройками для каждого устройства.
- Сеансы остаются подключёнными, пока клиент просмотра скрыт; вызвать его можно из трея/строки меню.
- Доступ через браузер по HTTPS, предоставляемый настольными хостами.
- Отдельный исполняемый файл `deskport`, пространство имён настроек Qt `DeskPort` и
  идентификатор приложения Linux `io.github.keithxc.DeskPort`.
- Оконный стриминг и управление абсолютным указателем по умолчанию.
- Отключение звука при потере фокуса; игровая оптимизация, мышь с геймпада, режим нескольких контроллеров,
  фоновый ввод с геймпада и статус Discord по умолчанию отключены.
- Нет запросов на обновление от upstream Moonlight для этого независимого приложения.
- Зафиксированное окружение Nix и процесс сборки для Linux.

Настольный интерфейс включает страницы устройств, демонстрации и настроек, с выбором языка
и отдельными разрешениями хоста. Закрытие клиента просмотра сохраняет его сеанс и открывает список устройств.
Для активного устройства доступно «Вернуться к рабочему столу»; другие устройства показывают сведения, пока
текущий сеанс не будет отключён. Закрепляйте часто используемые устройства и выбирайте компактный
список или карточки. Оформление следует системе, с возможностью принудительно выбрать светлую или тёмную тему.

## Охват платформ

Статус выпуска по каждой платформе см. в [таблице платформ](#поддерживаемые-платформы)
выше. Настольные выпуски охватывают macOS Apple Silicon, Linux x86_64 и Windows x64
в роли как клиента просмотра, так и хоста; мобильные приложения — только клиенты.

Поддержка клиентских платформ и поддержка хостов разделены: хост на Mac не требует
клиента DeskPort для Mac. Аппаратное декодирование, ввод в реальном времени, качество изображения и задержка вызова требуют
проверки в реальных сеансах; успешная сборка их не подтверждает.

## Следующая веха

Сохранять один сеанс подключённым в течение **50 циклов скрытия/показа**, показывать окно в
текущем рабочем пространстве и надёжно возвращать локальный ввод. Измерять задержку свежего кадра
и фоновое потребление ресурсов отдельно от появления окна.

Критерии приёмки и отложенные функции см. в [дорожной карте](../ROADMAP.md),
а происхождение и границы сопровождения — в [заметках об upstream](../UPSTREAM.md).

## Проверка

```sh
nix build
python3 scripts/deskport-smoke.py ./result
```

Smoke-проверка использует временные каталоги конфигурации/кэша XDG и закадровую
платформу Qt. Она не выполняет сопряжение с хостом, не запускает поток и не внедряет ввод.

## Повседневное управление

Закрытие окна оставляет DeskPort работать в трее/строке меню. Используйте **Open DeskPort**,
чтобы вызвать его, **Disconnect viewer**, чтобы завершить только текущее подключение, или
**Quit DeskPort**, чтобы завершить службу. Локальная демонстрация продолжается после закрытия клиента просмотра.

Общий буфер обмена для простого текста и перехват системных сочетаний клавиш по умолчанию включены на
обоих связанных устройствах. Изменения настроек применяются после переподключения. Передаются только новые копии,
до 1 МиБ. Поддерживаемые изображения и файлы загружаются по запросу между
совместимыми настольными устройствами, на которых это включено; см. [ограничения](../CLIPBOARD.md). В режиме настольного
указателя клавиатурный ввод следует за указателем внутри активного видео.
**Ctrl+Alt+Shift+Z** освобождает ввод;
**Ctrl+Alt+Shift+Q** отключает клиент просмотра. Щёлкните внутри, чтобы вернуть ввод после
явного освобождения. Сочетания, зарезервированные ОС, зависят от композитора рабочего стола.

Автозапуск при входе и восстановление требуют активного графического сеанса. Прежде чем полагаться
на компьютер для доступа без присмотра, см. [проверки приёмки и ограничения](../INPUT_SERVICE_ACCEPTANCE.md).

## Лицензия и благодарности

DeskPort — независимый производный проект от [Moonlight Qt](https://github.com/moonlight-stream/moonlight-qt),

Moonlight обеспечивает основу стриминга; [Sunshine](https://github.com/LizardByte/Sunshine)
входит в хост-пакеты macOS, Windows и Linux (кроме Flatpak, работающего только для просмотра) и предоставляется пакетом Nix для Linux.
Отдельно установленные службы Sunshine остаются независимыми.

затем создайте ZIP с журналами и откройте черновик issue на GitHub. Проверьте ZIP перед прикреплением:

вас. См. [диагностические данные и ограничения](../DIAGNOSTICS.md).
