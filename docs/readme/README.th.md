## คุณสมบัติหลัก

- **แอปเดสก์ท็อปเดียวสำหรับดูและแชร์** มี Sunshine ในตัว การอนุมัติอุปกรณ์ ข้อมูลรับรองและการตั้งค่าแยกอิสระ
  แพ็กเกจโฮสต์สำหรับ macOS, Windows และ Linux ไม่ต้องติดตั้ง Sunshine แยก (ยกเว้น Flatpak ที่ใช้ดูได้อย่างเดียว)
- **พื้นที่ทำงานที่ปรับตามไคลเอนต์** ปรับขนาดอัตโนมัติบนโฮสต์ macOS และ KDE ที่รองรับ, HiDPI,
  เลย์เอาต์มือถือแนวตั้ง/แนวนอน และปรับขนาดแยกตามอุปกรณ์
  การเปลี่ยนขนาดจะเชื่อมต่อวิดีโอใหม่ชั่วครู่ ไม่ใช่การสลับตัวเข้ารหัสแบบไร้รอยต่อ
- **เลือกนโยบายจอแสดงผลของโฮสต์** จอหลักเสมือนพร้อมจอสะท้อน, จอหลักเสมือนโดยปิดจออื่น
  หรือพื้นที่ทำงานแบบขยายบนโฮสต์ที่รองรับ DeskPort จะคืนค่าเลย์เอาต์ที่บันทึกไว้เมื่อเซสชันจบ
- **สลับระหว่างอุปกรณ์ที่ได้รับอนุญาต** ยืนยันก่อนเข้าควบคุมเซสชันที่กำลังใช้งาน
  ไคลเอนต์ที่ถูกแทนที่จะได้รับคำอธิบายการเข้าควบคุมที่ผ่านการยืนยันตัวตน
- **งานบนเดสก์ท็อปอยู่ใกล้มือเสมอ** ซ่อนและเรียกตัวแสดงผลที่เชื่อมต่ออยู่กลับมา ปล่อยอินพุตระยะไกลเมื่อซ่อน
  และตัดการดูแยกจากการแชร์ภายในเครื่อง
- **บันทึกการตั้งค่าแยกตามคอมพิวเตอร์** ภาพ เสียง อินพุต การปรับแต่งเดสก์ท็อป และการแก้ไขที่อยู่จะผูกกับอุปกรณ์
  พร้อมการ์ด การปักหมุด ธีม และอินเทอร์เฟซหลายภาษา
- **แชร์คลิปบอร์ดเมื่อต้องการ** ข้อความอัปเดตทันที ส่วนรูปภาพและไฟล์ที่รองรับจะดึงเมื่อร้องขอ
  ระหว่างเครื่องเดสก์ท็อปที่ผูกกันและเลือกเปิดใช้ ดู[ขอบเขตและข้อจำกัดของคลิปบอร์ด](../CLIPBOARD.md)
- **การควบคุมบนมือถือแบบเนทีฟ** iPhone/iPad และไคลเอนต์ Androidมีอินพุตแบบสัมผัส/แทร็กแพด
  การควบคุมด้วยคีย์บอร์ด และการเข้าสู่เดสก์ท็อประยะไกลโดยตรง
- **เริ่มทำงานเมื่อเข้าสู่ระบบและการกู้คืนบน macOS (ไม่บังคับ)** ต้องมีการเข้าสู่ระบบแบบกราฟิกที่ใช้งานอยู่
  และการอนุมัติของระบบ ไม่ได้ปลดล็อก FileVault หรือเข้าสู่ระบบแทนคุณ

> เราไม่พบกรณีนี้ในการทดสอบของเราเอง โปรดเปิด Defender ไว้ หากมีคำเตือน

และรุ่นพกพาจะลงทะเบียนพาธตัวช่วยแสดงผลปัจจุบันอัตโนมัติเมื่อเริ่มแชร์ อินพุตบนโฮสต์ยังต้องการสิทธิ์อุปกรณ์ แอปมือถือไม่สามารถเป็นโฮสต์เดสก์ท็อปได้
การมีเพียงคำจำกัดความซอร์สหรือคอมไพล์สำเร็จไม่ได้ทำให้แพลตฟอร์มนั้นได้รับการรองรับ

การซื้อช่วยสนับสนุนการลงนาม ฮาร์ดแวร์ทดสอบ และการพัฒนาต่อเนื่อง

ใช้ LAN หรือ VPN ของคุณเอง เช่น Tailscale DeskPort ไม่มีบริการบัญชี เดสก์ท็อปที่โฮสต์ไว้ รีเลย์ หรืออุโมงค์เครือข่าย
การจับคู่ด้วย PIN ของ Sunshine แบบเดิมยังใช้ได้

**0.7.3 เสถียร:** การอัปเดตเดสก์ท็อปนี้นำแคตตาล็อก UI ที่ใช้ร่วมกัน 22 ภาษา พร้อมคำแปลเดสก์ท็อปแบบเดิมเพิ่มเติม

### การติดตั้งบน Linux ตามดิสทริบิวชัน

คำแนะนำเหล่านี้สำหรับระบบเดสก์ท็อป **x86_64** และไฟล์ดาวน์โหลดรุ่น **0.7.3** แพ็กเกจเนทีฟต้องใช้ glibc 2.39 ขึ้นไป
ไฟล์เหล่านี้ดาวน์โหลดจากโปรเจกต์ต้นทาง ไม่ใช่แพ็กเกจจากคลังของดิสทริบิวชันสำหรับ DeskPort สำหรับรุ่นต่อไปให้ดาวน์โหลดและตรวจสอบแพ็กเกจใหม่อีกครั้ง

AppImage 0.7.3 ยังคงการแก้ไขรันไทม์พกพา การคืนค่าจอ การปิดโปรเซส สิทธิ์ และการเริ่มเมื่อเข้าสู่ระบบสำหรับ Bazzite/KDE Wayland
[issue #5](https://github.com/keithxc/deskport/issues/5) รวมถึงแบ็กพอร์ตเล็ก ๆ จาก Qt Wayland 6.4.2 แบ็กพอร์ตนี้ใช้เฉพาะ AppImage
แพ็กเกจเนทีฟและ Flatpak ยังใช้รันไทม์ Qt พื้นฐาน AppImage **0.7.3** สุดท้ายผ่านการเริ่ม FUSE ตามปกติและการตรวจตัวช่วย/รันไทม์
ใน VM Bazzite KDE Wayland ใหม่ที่เปิด SELinux Enforcing และใช้กราฟิกแบบซอฟต์แวร์ สิ่งนี้ไม่ได้ยืนยัน GPU จริงหรือการสตรีมจริง
ดู[ขอบเขตการตรวจสอบ 0.7.3](../releases/RELEASE_0.7.3.md#validation-boundary)

ผลการติดตั้ง อัปเกรด ย้อนกลับ ถอดออก และการคงค่าการตั้งค่าใน VM เต็มรูปแบบติดตามอยู่ใน[เมทริกซ์วงจรชีวิตเดสก์ท็อป](../LINUX_DESKTOP_ACCEPTANCE.md)
การทดสอบ GUI เบื้องต้นของ AppImage ไม่ได้ยืนยันการทำงานของแพ็กเกจเนทีฟ การติดตั้งแพ็กเกจและเปิด GUI เพียงอย่างเดียว
ไม่ได้ยืนยันการจับภาพสด การถอดรหัสวิดีโอด้วยฮาร์ดแวร์ อินพุตระยะไกล คุณภาพภาพ หรือความหน่วง

VM Ubuntu 26.04 GNOME ที่เก็บไว้ทำให้เกิดการแครชตอนเริ่มซ้ำได้ในไลบรารี VA-API Wayland ส่วนตัวรุ่นเก่าของ DEB 0.7.2 ที่เผยแพร่
DEB 0.7.3 สุดท้ายใช้ libva 2.23.0 ที่ตรึงรุ่นไว้ในทั้งสองโครงรันไทม์ส่วนตัว และแยกยูทิลิตีระบบออกจากการแทนที่ไลบรารีของโฮสต์
ผ่านการตรวจ GUI/API และการอัปเกรดในโอเวอร์เลย์ใหม่ของ VM นั้น การตั้งค่าจำลองยังสมบูรณ์ตลอดการย้อนกลับและถอนการติดตั้ง
และการแครชของรุ่นเก่าเกิดซ้ำได้ก่อนอัปเกรดและหลังย้อนกลับ ไฟล์รุ่นเผยแพร่ที่มีอยู่ยังคงแฮชเดิม การเริ่มจับภาพบน GNOME
และการสร้างเอาต์พุตเสมือนซ้ำ ๆ ยังเป็นช่องว่างการตรวจรับแยกต่างหาก และ KWin 6.3 ของ Debian 13 ยังต่ำกว่าขั้นต่ำ 6.6 ของตัวช่วยแสดงผลโฮสต์

| ดิสทริบิวชัน / เดสก์ท็อป | วิธีดาวน์โหลด |
| --- | --- |
| Ubuntu 26.04 GNOME | DEB หรือ AppImage 0.7.3; ผ่านการทดสอบการแครชตอนเริ่มของ DEB แล้ว ยังมีช่องว่างด้านการจับภาพ/การกู้คืนบน GNOME |
| Debian 13 KDE | DEB ติดตั้งด้วย APT |

เปิดเทอร์มินัลในเซสชันเดสก์ท็อปปกติ ชุดคำสั่งแต่ละชุดจะตรวจชื่อไฟล์ที่ดาวน์โหลดตรงกับ `SHA256SUMS.txt` ของรุ่นนั้นก่อนติดตั้ง
เช็กซัมต้องรายงานไฟล์นั้นว่า `OK` หากไม่มีรายการหรือค่าไม่ตรง ชุดคำสั่งจะหยุด
หลังติดตั้ง ให้เปิด DeskPort ในฐานะผู้ใช้ทั่วไป
ก่อนอัปเกรด ให้หยุดการแชร์และปิด DeskPort ตัวเก่าให้สนิทด้วยคำสั่ง **Quit** เช่นจากเมนูถาด การปิดหน้าต่างอาจแค่ซ่อนไว้
จากนั้นเปิดรุ่นที่ติดตั้งใหม่เพื่อให้ไบนารีใหม่ทำงาน

<summary><strong>Ubuntu 26.04 GNOME</strong> — ดาวน์โหลด ติดตั้ง อัปเดต และถอดออก</summary>

ดาวน์โหลด [deskport_0.7.3-1_amd64.deb](https://github.com/keithxc/deskport/releases/download/v0.7.3/deskport_0.7.3-1_amd64.deb)
แล้วเปิดเทอร์มินัลในไดเรกทอรีที่มีไฟล์นั้น:

```sh
curl --fail --location --output SHA256SUMS.txt https://github.com/keithxc/deskport/releases/download/v0.7.3/SHA256SUMS.txt &&
awk '$2 == "deskport_0.7.3-1_amd64.deb" { print }' SHA256SUMS.txt | sha256sum --check - &&
sudo apt update &&
sudo apt install ./deskport_0.7.3-1_amd64.deb &&
deskport
```

APT ติดตั้งดีเพนเดนซีจากคลัง Ubuntu ที่ตั้งค่าไว้ `./` ด้านหน้าใช้เลือกไฟล์ที่ดาวน์โหลด ครั้งต่อไปให้เปิด DeskPort จากเมนูแอป
หากต้องการอัปเกรด ให้ดาวน์โหลด DEB รุ่นถัดไปที่เข้ากันได้ ตรวจเช็กซัม แล้วรัน `sudo apt install ./NEW_FILENAME.deb`
ด้วยชื่อไฟล์จริงอีกครั้ง ถอดแพ็กเกจด้วย `sudo apt remove deskport`

เปิดตามปกติ ไม่ต้องลบหรือย้ายไลบรารีที่มากับแพ็กเกจ หากการเริ่มเมื่อเข้าสู่ระบบชี้ไปยัง AppImage ตัวเก่า

ให้ทำตามขั้นตอนนี้แทนการติดตั้งแพ็กเกจเนทีฟ

[คู่มือ AppImage](https://docs.bazzite.gg/Installing_and_Managing_Software/AppImage/) ของ Bazzite อธิบาย Gear Lever

ทดสอบการแชร์กับไคลเอนต์บน LAN หรือ VPN ที่ต้องการก่อนเปิดการเริ่มเมื่อเข้าสู่ระบบ (ไม่บังคับ) การติดตั้งแพ็กเกจไม่ได้ตั้งค่า
การเข้าถึงเครือข่ายหรือให้สิทธิ์อินพุตบนโฮสต์ หยุดการแชร์และออกจาก DeskPort ก่อนถอดแพ็กเกจ และปิดการเริ่มเมื่อเข้าสู่ระบบหากเคยเปิดไว้
การถอดแพ็กเกจจะเก็บการตั้งค่า DeskPort ในโฮมไดเรกทอรีไว้

### สถานะในคลัง Linux

| ช่องทาง | สถานะ | การติดตั้ง |
| --- | --- | --- |
| แพ็กเกจรุ่นเผยแพร่บน GitHub | 0.7.3 เสถียร | ดาวน์โหลดแพ็กเกจสำหรับดิสทริบิวชันของคุณจากด้านบน |

## บิลด์และรันบน Linux

เมื่อเปิดใช้ Nix และ flakes:

```sh
git clone https://github.com/keithxc/deskport.git
cd deskport
nix build
./result/bin/deskport
```

ดีเพนเดนซีซอร์สจากบุคคลที่สามของตัวแสดงผลรวมอยู่ในคลังแล้ว ส่วนแกนกลางที่ใช้ร่วมกันและอินพุตบิลด์ของ Nix ยังเป็นดีเพนเดนซีภายนอกที่ตรึงรุ่นไว้
บิลด์แบบเนทีฟต้องเริ่มต้น `shared/deskport-core` ดู [docs/VENDORED.md](../VENDORED.md)
สำหรับการตั้งค่า SSH การจัดการโฮสต์ภายในเครื่อง ข้อกำหนด VPS และ Omarchy/Hyprland ดู[คู่มือ CLI](../CLI.md)
`deskport doctor` ตรวจข้อกำหนดการเป็นโฮสต์ `deskport status --json` ตรวจอินสแตนซ์ที่กำลังทำงานโดยไม่เปิดหน้าต่าง
`nix run . -- --help` แสดงอินเทอร์เฟซบรรทัดคำสั่ง เริ่มแชร์บนโฮสต์และผูกอุปกรณ์ก่อนเชื่อมต่อ การจับคู่ด้วย PIN ของ Sunshine
แบบเดิมก็ใช้ได้ ไม่มีข้อมูลโฮสต์หรือการจับคู่ส่วนตัวรวมไว้หรือนำเข้าจาก Moonlight
ที่อยู่ที่ป้อนเองใหม่จะใช้พอร์ต `48989` ของ DeskPort เป็นค่าเริ่มต้น หากพอร์ตที่แสดงบนหน้าการแชร์ของโฮสต์ต่างออกไปให้ระบุพอร์ตนั้น
หรือใช้ `host:47989` เพื่อเชื่อมต่อกับการติดตั้ง Sunshine แบบสแตนด์อโลนค่าเริ่มต้นอย่างชัดเจน ปลายทางที่บันทึก/ค้นพบจะใช้พอร์ตของตัวเอง

สำหรับบิลด์เนทีฟที่แก้ไขได้:

```sh
git submodule update --init shared/deskport-core
nix develop
mkdir -p build
cd build
qmake ../moonlight-qt.pro CONFIG+=disable-prebuilts
make -j4
./app/deskport
```

ชื่อไฟล์ของโปรเจกต์ต้นทางยังคงเดิมเพื่อให้ตรวจทาน fork ได้ง่าย

## แตกต่างจาก Moonlight อย่างไร?

- โฮสต์ Sunshine ในตัว พร้อมการอนุมัติอุปกรณ์ การเข้าควบคุม และการตั้งค่ารายอุปกรณ์
- เซสชันยังเชื่อมต่ออยู่ขณะซ่อนตัวแสดงผล เรียกกลับได้จากถาด/แถบเมนู
- การเข้าถึงผ่านเบราว์เซอร์ด้วย HTTPS ที่ให้บริการโดยโฮสต์เดสก์ท็อป
- ไฟล์ปฏิบัติการ `deskport` แยกต่างหาก เนมสเปซการตั้งค่า Qt `DeskPort` และ
  รหัสแอป Linux `io.github.keithxc.DeskPort`
- สตรีมแบบหน้าต่างและควบคุมด้วยตัวชี้แบบสัมบูรณ์เป็นค่าเริ่มต้น
- ปิดเสียงเมื่อเสียโฟกัส ปิดการปรับแต่งเกม เมาส์จากเกมแพด โหมดหลายคอนโทรลเลอร์ อินพุตเกมแพดเบื้องหลัง
  และสถานะ Discord เป็นค่าเริ่มต้น
- ไม่มีการแจ้งอัปเดตจาก Moonlight ต้นทางสำหรับแอปอิสระนี้
- สภาพแวดล้อม Nix ที่ล็อกไว้และเวิร์กโฟลว์บิลด์ Linux

อินเทอร์เฟซเดสก์ท็อปมีหน้าอุปกรณ์ การแชร์ และการตั้งค่า พร้อมการเลือกภาษาและสิทธิ์โฮสต์แยกกัน การปิดตัวแสดงผลจะคงเซสชันไว้
และเปิดรายการอุปกรณ์ อุปกรณ์ที่ใช้งานอยู่มีตัวเลือกกลับสู่เดสก์ท็อป อุปกรณ์อื่นจะแสดงรายละเอียดจนกว่าเซสชันปัจจุบันจะถูกตัด
ปักหมุดอุปกรณ์ที่ใช้บ่อยและเลือกรายการแบบกะทัดรัดหรือการ์ด ลักษณะหน้าตาเป็นไปตามระบบ โดยบังคับโหมดสว่างหรือมืดได้

## ขอบเขตแพลตฟอร์ม

ดูสถานะรุ่นเผยแพร่ของแต่ละแพลตฟอร์มใน[ตารางแพลตฟอร์ม](#แพลตฟอร์มที่รองรับ)ด้านบน รุ่นเดสก์ท็อปครอบคลุม macOS Apple Silicon,
Linux x86_64 และ Windows x64 ทั้งในฐานะตัวแสดงผลและโฮสต์ แอปมือถือเป็นไคลเอนต์เท่านั้น

การรองรับไคลเอนต์และโฮสต์แยกจากกัน โฮสต์ Mac ไม่จำเป็นต้องใช้ไคลเอนต์ DeskPort บน Mac การถอดรหัสด้วยฮาร์ดแวร์ อินพุตสด
คุณภาพภาพ และความหน่วงในการเรียกกลับต้องทดสอบในเซสชันจริง การบิลด์สำเร็จไม่ได้พิสูจน์สิ่งเหล่านี้

## หมุดหมายถัดไป

รักษาเซสชันเดียวให้เชื่อมต่อตลอด **50 รอบการซ่อน/แสดง** แสดงหน้าต่างบนพื้นที่ทำงานปัจจุบัน และคืนอินพุตภายในเครื่องได้อย่างเชื่อถือได้
วัดความหน่วงของเฟรมใหม่และการใช้ทรัพยากรเบื้องหลังแยกจากการปรากฏของหน้าต่าง

ดู[แผนงาน](../ROADMAP.md) สำหรับเกณฑ์การตรวจรับและฟีเจอร์ที่เลื่อนออกไป และ[บันทึกโปรเจกต์ต้นทาง](../UPSTREAM.md)
สำหรับที่มาและขอบเขตการดูแลรักษา

## การตรวจสอบ

```sh
nix build
python3 scripts/deskport-smoke.py ./result
```

การทดสอบเบื้องต้นใช้ไดเรกทอรีการตั้งค่า/แคช XDG ชั่วคราวและแพลตฟอร์ม Qt แบบนอกหน้าจอ ไม่จับคู่กับโฮสต์ ไม่เริ่มสตรีม และไม่ส่งอินพุต

## การควบคุมเดสก์ท็อปประจำวัน

การปิดหน้าต่างทำให้ DeskPort ยังทำงานในถาด/แถบเมนู ใช้ **Open DeskPort** เพื่อเรียกกลับ, **Disconnect viewer**
เพื่อตัดเฉพาะการเชื่อมต่อปัจจุบัน หรือ **Quit DeskPort** เพื่อออกจากบริการ การแชร์ภายในเครื่องยังดำเนินต่อเมื่อปิดตัวแสดงผล

การแชร์คลิปบอร์ดข้อความธรรมดาและการจับคีย์ลัดระบบเปิดเป็นค่าเริ่มต้นบนอุปกรณ์ที่ผูกกันทั้งสองเครื่อง การเปลี่ยนการตั้งค่ามีผลหลังเชื่อมต่อใหม่
แชร์เฉพาะการคัดลอกใหม่ สูงสุด 1 MiB รูปภาพและไฟล์ที่รองรับจะดึงเมื่อร้องขอระหว่างเครื่องเดสก์ท็อปที่เข้ากันได้และเลือกเปิดใช้
ดู[ข้อจำกัด](../CLIPBOARD.md) ในโหมดตัวชี้เดสก์ท็อป การส่งคีย์บอร์ดจะตามตัวชี้ภายในวิดีโอที่โฟกัสอยู่
**Ctrl+Alt+Shift+Z** ปล่อยอินพุต
**Ctrl+Alt+Shift+Q** ตัดการเชื่อมต่อตัวแสดงผล คลิกด้านในเพื่อรับอินพุตคืนหลังปล่อยอย่างชัดเจน คีย์ลัดที่ระบบสงวนไว้ขึ้นกับคอมโพสิเตอร์ของเดสก์ท็อป

การเริ่มเมื่อเข้าสู่ระบบและการกู้คืนต้องมีเซสชันเข้าสู่ระบบแบบกราฟิกที่ใช้งานอยู่ ดู[การตรวจรับและข้อจำกัด](../INPUT_SERVICE_ACCEPTANCE.md)
ก่อนพึ่งพาคอมพิวเตอร์สำหรับการเข้าถึงแบบไม่ต้องดูแล

## สัญญาอนุญาตและการให้เครดิต

DeskPort เป็นงานดัดแปลงอิสระจาก [Moonlight Qt](https://github.com/moonlight-stream/moonlight-qt) ซึ่งเริ่มต้นจาก v6.1.0

บริการ Sunshine ที่ติดตั้งแยกจะคงเป็นอิสระ

GPL-3.0-or-later ดู [LICENSE](../../LICENSE) ประกาศในซอร์สที่คงไว้ และสัญญาอนุญาตของดีเพนเดนซีแต่ละตัวที่ระบุใน
[docs/VENDORED.md](../VENDORED.md) เอกสารต้นฉบับเก็บไว้ใน [README.upstream.md](README.upstream.md)
