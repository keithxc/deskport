## གཙོ་བོའི་ཁྱད་ཆོས།

- **ལྟ་བ་དང་མཉམ་སྤྱོད་ཀྱི་ཅོག་ངོས་ཉེར་སྤྱོད་གཅིག** Sunshine ནང་འདུས། སྒྲིག་ཆས་ཆོག་མཆན། རང་དབང་གི་ངོས་འཛིན་དང་སྒྲིག་འགོད།
  macOS དང་ Windows, Linux གི་ host ཐུམ་སྒྲིལ་ལ་ Sunshine ལོགས་སུ་སྒྲིག་འཇུག་མི་དགོས། (ལྟ་བ་ཙམ་གྱི་ Flatpak མ་གཏོགས།)
- **མཁོ་སྤྱོད་པ་ (client) རྗེས་འབྲང་གི་ལས་ཀའི་ས་ཁུལ།** མཐུན་པའི་ macOS དང་ KDE host ཐོག་ཆེ་ཆུང་རང་འགྱུར། HiDPI,
  ཁ་པར་གྱི་གྱེན་ཕྱོགས/འཕྲེད་ཕྱོགས་བཀོད་པ། སྒྲིག་ཆས་རེ་རེར་ཆེ་ཆུང་ལེགས་སྒྲིག
  ཆེ་ཆུང་བསྒྱུར་སྐབས་བརྙན་ཟློས་སྐར་ཆ་ཁ་ཤས་རིང་ཡང་བསྐྱར་སྦྲེལ་གྱི་ཡོད། encoder བར་མཚམས་མེད་པའི་བརྗེ་སྒྱུར་མིན།
- **host གི་བརྙན་ཡོལ་སྲིད་ཇུས་འདེམས་པ།** རྟོག་བཟོའི་བརྙན་ཡོལ་གཙོ་བོ་དང་བརྙན་ཡོལ་གཞན་མེ་ལོང་ལྟར་སྟོན་པ། ཡང་ན་
  བརྙན་ཡོལ་གཞན་སྒོ་བརྒྱབ་པ། ཡང་ན་ནུས་ལྡན་ host ཐོག་ལས་ཀའི་ས་ཁུལ་རྒྱ་བསྐྱེད། མཐུད་ཚད་མཇུག་རྫོགས་སྐབས་ DeskPort གིས་
  ཉར་ཚགས་བྱས་པའི་བཀོད་པ་སླར་གསོ་བྱེད།
- **ཆོག་མཆན་ཐོབ་པའི་སྒྲིག་ཆས་བར་འགྱུར་བ།** བྱེད་བཞིན་པའི་མཐུད་ཚད་ལེན་གོང་ངེས་གཏན་བྱེད། ཚབ་བརྗེས་པའི་ client ལ་
  ངོས་འཛིན་ཐུབ་པའི་གསལ་བཤད་སྤྲོད།
- **ཅོག་ངོས་ཀྱི་ལས་ཀ་ལག་མཐིལ་དུ།** སྦྲེལ་ཡོད་པའི་ viewer སྦས་པ་དང་ཕྱིར་འབོད། སྦས་སྐབས་རྒྱང་རིང་ནང་འཇུག་གློད་པ།
  ས་གནས་མཉམ་སྤྱོད་དང་ལོགས་སུ་ལྟ་བ་མཚམས་གཅོད།
- **རྩིས་འཁོར་རེ་རེའི་སྒྲིག་འགོད་ཉར་ཚགས།** པར་རིས། སྒྲ། ནང་འཇུག ཅོག་ངོས་ལེགས་སྒྲིག ཁ་བྱང་རྩོམ་སྒྲིག་བཅས་སྒྲིག་ཆས་དང་མཉམ་དུ་གནས།
  ཤོག་བྱང་། བཏགས་པ། བརྗོད་གཞི་དང་སྐད་ཡིག་ས་གནས་ཅན་གྱི་ངོས་ལྡེབ།
- **དགོས་མཁོ་ལྟར་སྦྱར་སྡེར (clipboard) མཉམ་སྤྱོད།** ཡི་གེ་འཕྲལ་དུ་གསར་སྒྱུར། རྒྱབ་སྐྱོར་ཡོད་པའི་པར་རིས་དང་ཡིག་ཆ་
  མོས་མཐུན་བྱས་པའི་སྦྲེལ་ཡོད་ཅོག་ངོས་བར་དུ་རེ་ཞུ་བྱས་སྐབས་ལེན། [སྦྱར་སྡེར་གྱི་ཁྱབ་ཁོངས་དང་ཚད་བཀག](../CLIPBOARD.md) ལ་ལྟོས།
- **ཁ་པར་གྱི་རང་བཞིན་ཚོད་འཛིན།** iPhone/iPad དང་Android client ཡིས་རེག་ཐིག/trackpad ནང་འཇུག
  མཐེབ་གཞོང་ཚོད་འཛིན། རྒྱང་རིང་ཅོག་ངོས་སུ་ཐད་ཀར་འཛུལ་བ་བཅས་མཁོ་སྤྲོད།
- **ནང་འཛུལ་སྐབས་འགོ་སློང་དང་ macOS སླར་གསོ། (འདེམས་རུང་)** བྱེད་བཞིན་པའི་རི་མོའི་ནང་འཛུལ་དང་མ་ལག་གི་ཆོག་མཆན་དགོས།
  FileVault ཁ་འབྱེད་པ་དང་ཁྱེད་ཀྱི་ཚབ་ཏུ་ནང་འཛུལ་མི་བྱེད།
