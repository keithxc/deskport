DeskPort คืออะไร

  1. DeskPort แชร์คอมพิวเตอร์เครื่องหนึ่งและอนุญาตให้อุปกรณ์อื่นๆ ของคุณใช้เดสก์ท็อปได้
  2. คอมพิวเตอร์ที่ใช้คือโฮสต์ อุปกรณ์ที่คุณนั่งคือลูกค้า คอมพิวเตอร์สามารถเป็นได้ทั้งสองอย่าง
  3. อุปกรณ์จะผูกกันหนึ่งครั้ง การเข้าถึงได้รับการอนุมัติบนโฮสต์และสามารถเพิกถอนได้ที่นั่น
  4. DeskPort เก็บอุปกรณ์และการตั้งค่าที่บันทึกไว้บนอุปกรณ์นี้ โดยไม่ต้องมีบัญชี DeskPort

แบ่งปันคอมพิวเตอร์เครื่องนี้

  1. เปิดการแชร์ในแถบด้านบนแล้วเลือกเริ่มการแชร์
  2. ให้สิทธิ์การบันทึกหน้าจอและการเข้าถึงการเข้าถึงเมื่อถูกถาม การแชร์ดำเนินไปโดยไม่มีสิ่งเหล่านั้น แต่รูปภาพหรืออินพุตจะไม่ทำงาน
  3. จุดใต้ไอคอนการแชร์หมายความว่าคอมพิวเตอร์เครื่องนี้ถูกแชร์อยู่ในปัจจุบัน
  4. บน macOS หากภาพว่างเปล่าหรือควบคุมระยะไกลไม่ได้ ให้ตรวจสอบการบันทึกหน้าจอและการช่วยการเข้าถึงในการตั้งค่าระบบ «การแบ่งปัน» จะแสดงผลการตรวจสอบสิทธิ์และความพร้อม
  5. ซ่อนหน้าต่าง DeskPort เพื่อแชร์ต่อในเบื้องหลัง ใช้ «หยุดแชร์» เมื่อไม่ต้องการให้คอมพิวเตอร์เครื่องนี้รับการเชื่อมต่อเดสก์ท็อปอีก

เชื่อมต่อกับคอมพิวเตอร์

  1. อุปกรณ์บนเครือข่ายเดียวกันจะปรากฏในรายการอุปกรณ์ด้วยตัวเอง
  2. ใช้ เพิ่มอุปกรณ์ บนการ์ดเพิ่มสำหรับคอมพิวเตอร์บนเครือข่ายอื่น และป้อนที่อยู่ของมัน
  3. การเลือกอุปกรณ์ในครั้งแรกจะขอให้โฮสต์เข้าถึง อนุมัติคำขอที่นั่น
  4. หากมีอุปกรณ์อื่นเชื่อมต่ออยู่แล้ว ระบบจะถามว่าจะรับช่วงต่อหรือไม่ การรับช่วงต่อจะยกเลิกการเชื่อมต่ออุปกรณ์นั้น
  5. หากอยู่คนละเครือข่าย อุปกรณ์ทั้งสองยังต้องมีเส้นทางที่เชื่อมถึงกันได้ เช่น เครือข่าย VPN หรือ Tailscale ของคุณเอง การเพิ่มที่อยู่ไม่ได้สร้างเส้นทางดังกล่าว
  6. เปลี่ยนที่อยู่ในเมนูของการ์ดอุปกรณ์รับที่อยู่ได้หลายรายการ บรรทัดละหนึ่งรายการ และทั้งหมดใช้พอร์ตที่จับคู่ไว้ DeskPort จะลองทุกที่อยู่พร้อมกันและใช้ที่อยู่แรกในรายการที่ตอบกลับ จึงควรใส่ที่อยู่ LAN ไว้ก่อน แล้วตามด้วยโดเมนหรือที่อยู่ VPN คุณแก้ไขได้ระหว่างเชื่อมต่อ เซสชันที่เปิดอยู่จะใช้ที่อยู่ปัจจุบันต่อไป และการเชื่อมต่อครั้งถัดไปจะใช้รายการใหม่
  7. Sunshine และโฮสต์ที่ไม่รองรับการผูก DeskPort ใช้ «เพิ่มโฮสต์แบบเดิม» และการจับคู่ด้วย PIN เปิดแอปโฮสต์ค้างไว้เพื่ออนุมัติ PIN
  8. หากต้องการเพิกถอนการควบคุม ให้ลบสิทธิ์การเข้าถึงที่บันทึกไว้ใน «การแบ่งปัน» บนคอมพิวเตอร์ที่แชร์ การลบการ์ดจาก «อุปกรณ์» กับการเพิกถอนสิทธิ์เป็นคนละขั้นตอน เมื่อต้องการยกเลิกการผูกคอมพิวเตอร์สองเครื่อง ให้ลบสิทธิ์ทั้งสองทิศทาง

จัดระเบียบรายการอุปกรณ์

  1. แก้ไขในแถบด้านบนเริ่มโหมดแก้ไข ลากการ์ดเพื่อเรียงลำดับใหม่
  2. วางอุปกรณ์เครื่องหนึ่งไปยังอีกเครื่องหนึ่งเพื่อจัดกลุ่ม เช่น โฟลเดอร์บนหน้าจอหลักของโทรศัพท์
  3. ตั้งชื่อแทนในเมนูของการ์ดจะเปลี่ยนชื่ออุปกรณ์สำหรับอุปกรณ์นี้เท่านั้น
  4. รีเฟรชจะตรวจสอบอุปกรณ์ที่บันทึกไว้อีกครั้งและค้นหาอุปกรณ์ใหม่
  5. เปิดเมนูของการ์ดอุปกรณ์เพื่อดูสถานะ ที่อยู่ และคำสั่งเชื่อมต่อ «เปลี่ยนที่อยู่» จะอัปเดตรายการเชื่อมต่อที่บันทึกไว้ ส่วนชื่อแทนจะไม่เปลี่ยนชื่อคอมพิวเตอร์ระยะไกล

หน้าต่างและเซสชันเบื้องหลัง

  1. บนคอมพิวเตอร์ การปิดหรือซ่อนหน้าต่างแสดงผลจะยังคงเชื่อมต่อเซสชันไว้ในเบื้องหลัง «ตัดการเชื่อมต่อ» จะสิ้นสุดการเชื่อมต่อนั้น ส่วน «ล้มเลิก» จะออกจาก DeskPort
  2. เรียกเดสก์ท็อปที่ใช้งานอยู่กลับมาจากเมนูถาดระบบหรือรายการอุปกรณ์ หากมีหลายเซสชัน ให้เลือกเซสชันที่ต้องการจากเมนูเซสชัน
  3. การซ่อนหน้าต่างแสดงผลหรือย้ายโฟกัสออกจะปล่อยปุ่มและแป้นที่กดค้างไว้บนเครื่องระยะไกล คุณยังใช้คอมพิวเตอร์เครื่องนี้ได้ขณะที่เซสชันระยะไกลยังเชื่อมต่ออยู่
  4. ใช้ «เชื่อมต่อใหม่» ในเมนูอุปกรณ์หากเซสชันต้องการเชื่อมต่อใหม่ หรือเมื่อต้องการใช้การตั้งค่าสตรีมที่บันทึกไว้

แป้นพิมพ์ลัดบนคอมพิวเตอร์

  1. Meta + ' ใช้แสดงหรือซ่อน DeskPort: ใช้ Command + ' บน macOS, Windows + ' บน Windows หรือ Super + ' บน Linux ปล่อยปุ่มเพื่อเรียกใช้งาน ปุ่มลัดนี้จะเรียกเซสชันที่เลือกกลับมา หรือเปิด «อุปกรณ์» หากไม่มีเซสชันที่เชื่อมต่ออยู่
  2. การตั้งค่า → แป้นพิมพ์ลัด → ปุ่มลัดหน้าต่างทั้งระบบ เปิดอยู่ตามค่าเริ่มต้น การปิดจะยกเลิกการผูกปุ่มกับระบบและปิดกลไกปุ่มลัดสำรองในหน้าต่างแสดงผลทันที ตัวเลือกนี้จะถูกบันทึกไว้บนคอมพิวเตอร์เครื่องนี้
  3. ใน การตั้งค่า → แป้นพิมพ์ลัด ให้คลิกชุดปุ่มปัจจุบันในแถว «ปุ่มลัดหน้าต่างทั้งระบบ» กดชุดปุ่มหรือใช้ «เลือกปุ่ม» แล้วบันทึก การผูกปุ่มใหม่จะมีผลทันทีบนคอมพิวเตอร์เครื่องนี้ «คืนค่าเริ่มต้น» จะคืนเป็น Meta + ปุ่มอัญประกาศเดี่ยว ' (Command + ปุ่มอัญประกาศเดี่ยว ' บน macOS) ส่วน «ยกเลิก» จะคงการผูกปุ่มเดิมไว้ ระหว่างบันทึกปุ่ม ปุ่มลัดทั้งระบบจะหยุดทำงานชั่วคราว
  4. KDE Plasma มักกำหนด Meta+1–9 ให้รายการในตัวจัดการงาน หากการบันทึกปุ่มไม่ตอบสนอง ให้ใช้ «เลือกปุ่ม» เพื่อป้อนชุดปุ่ม เมื่อบันทึก เดสก์ท็อปอาจขอให้คุณแก้ปัญหาปุ่มลัดซ้ำกัน หรือคุณจะเลือกชุดปุ่มอื่นก็ได้
  5. บน Wayland เดสก์ท็อปอาจขออนุญาตและให้คุณเลือกการผูกปุ่ม โดยจะใช้ปุ่มลัดที่เดสก์ท็อปเลือกเป็นหลัก หากการลงทะเบียนถูกปฏิเสธ ไม่รองรับ หรือมีการใช้ปุ่มลัดนั้นอยู่แล้ว ให้ใช้ถาดระบบหรือรายการอุปกรณ์ DeskPort จะไม่แทนที่การผูกปุ่มของแอปอื่น
  6. ระหว่างเชื่อมต่อเดสก์ท็อป Ctrl+Alt+Shift+Z จะปล่อยหรือจับอินพุตระยะไกลอีกครั้ง X ใช้สลับเต็มหน้าจอ และ N ใช้สลับไปยังเดสก์ท็อปถัดไปที่เชื่อมต่ออยู่ ให้กด Ctrl+Alt+Shift ค้างไว้ร่วมกับตัวอักษรแต่ละตัว
  7. Ctrl+Alt+Shift+S ใช้แสดงหรือซ่อนสถิติการสตรีม D ใช้ย่อหน้าต่างแสดงผล M ใช้สลับโหมดตัวชี้ C ใช้แสดงหรือซ่อนตัวชี้ของเครื่องนี้ในโหมดเดสก์ท็อป และ L ใช้เปิดหรือปิดการจำกัดตัวชี้ให้อยู่ในหน้าต่าง
  8. Ctrl+Alt+Shift+V ส่งข้อความจากคลิปบอร์ดของเครื่องนี้เสมือนพิมพ์ด้วยแป้นพิมพ์ Q จะออกจากเต็มหน้าจอก่อน และเมื่อกด Ctrl+Alt+Shift+Q อีกครั้งในโหมดหน้าต่างจะตัดการเชื่อมต่อ

เต็มจอ

  1. บนคอมพิวเตอร์ ใช้ การตั้งค่าอุปกรณ์ → การตั้งค่าการสตรีมขั้นสูง → หน้าต่างการเชื่อมต่อ เพื่อเลือก «หน้าต่าง», «เต็มจอ» หรือ «เต็มจอไร้ขอบ» สำหรับการเชื่อมต่อครั้งถัดไป
  2. บนคอมพิวเตอร์ Ctrl+Alt+Shift+X จะเปิดและปิดเต็มหน้าจอระหว่างการเชื่อมต่อ บนโทรศัพท์หรือแท็บเล็ต จะนำปุ่มลอยกลับมา
  3. โทรศัพท์และแท็บเล็ตจะแสดงเดสก์ท็อประยะไกลเต็มหน้าจอเสมอ แตะปุ่มลอยสำหรับคีย์บอร์ด กดค้างไว้ที่เมนู
  4. โฮสต์สามารถขอให้อุปกรณ์ที่เชื่อมต่อออกจากโหมดเต็มหน้าจอได้ มันไม่เคยบังคับให้แสดงแบบเต็มหน้าจอ

รูปภาพและหน้าจอเสมือน

  1. เดสก์ท็อประยะไกลจะเป็นไปตามขนาดหน้าต่างของคุณ ดังนั้นการปรับขนาดหน้าต่างจะปรับขนาดเดสก์ท็อประยะไกล
  2. หน้าจอเสมือนจะตัดสินใจว่าจะเกิดอะไรขึ้นกับหน้าจอของโฮสต์ในขณะที่คุณเชื่อมต่อ
  3. การปรับแต่งเดสก์ท็อปอย่างละเอียดทำให้ทุกอย่างบนเดสก์ท็อประยะไกลใหญ่ขึ้นหรือเล็กลง
  4. การตั้งค่าเหล่านี้จะถูกบันทึกไว้ในแต่ละอุปกรณ์
  5. «พอดีกับหน้าต่าง» ใช้พิกเซลที่วาดภาพได้ของหน้าต่างแสดงผล ปิดตัวเลือกนี้เพื่อใช้ความละเอียดที่บันทึกไว้แทน ขนาดเดสก์ท็อปและการปรับขนาดที่ใช้ได้ยังขึ้นอยู่กับโฮสต์
  6. «การปรับแต่งเดสก์ท็อปอย่างละเอียด»: 1.5 ทำให้ส่วนควบคุมใหญ่ขึ้น ส่วน 0.5 แสดงเนื้อหาได้มากขึ้น การเปลี่ยนแปลงมีผลระหว่างเชื่อมต่อ ขนาดขั้นต่ำของโฮสต์อาจจำกัดการขยายเพิ่มเติม ให้ลองขยายหน้าต่างหรือใช้เต็มหน้าจอ
  7. «หลัก+กระจก» จะสะท้อนพื้นที่ทำงานระยะไกล «หลักเท่านั้น» จะปิดหน้าจออื่นของโฮสต์ และ «ขยาย» จะเพิ่มพื้นที่ทำงาน การรองรับขึ้นอยู่กับโฮสต์ เมื่อเซสชันสิ้นสุดจะคืนรูปแบบหน้าจอเดิม

แป้นพิมพ์ ตัวชี้ และคลิปบอร์ด

  1. การตั้งค่าอุปกรณ์ → ป้อนข้อมูล ควบคุมว่าจะส่งเหตุการณ์จากแป้นพิมพ์ ตัวชี้ และตัวควบคุมเกมหรือไม่ ปิดเพื่อดูอย่างเดียว ส่วน «เสียง» ควบคุมเสียงที่รับมาแยกต่างหาก
  2. การตั้งค่าการสตรีมขั้นสูง → คีย์บอร์ดและตัวชี้ มีโหมดตัวชี้ ทิศทางการเลื่อน การส่งต่อปุ่มลัดระบบ และการแชร์คลิปบอร์ดในเซสชัน
  3. บนโฮสต์ Mac ปุ่ม Super / Windows จะตรงกับ Command และ Alt จะตรงกับ Option ระบบปฏิบัติการอาจสงวนปุ่มลัดบางชุดไว้ ให้ใช้ Ctrl+Alt+Shift+Z เพื่อคืนการป้อนข้อมูลให้คอมพิวเตอร์เครื่องนี้
  4. «ใช้วิธีป้อนข้อมูลของเครื่องนี้» ปิดอยู่ตามค่าเริ่มต้น เปิดแยกสำหรับแต่ละอุปกรณ์แล้วเชื่อมต่อใหม่เพื่อพิมพ์ด้วย IME ของคอมพิวเตอร์เครื่องนี้ ตัวเลือกคำจะปรากฏใกล้มุมซ้ายบน ไม่ใช่ที่เคอร์เซอร์ข้อความระยะไกล หากจำเป็น ให้ใช้ IME ของเครื่องระยะไกลหรือแป้นพิมพ์จริงสำหรับเกม
  5. การแชร์คลิปบอร์ดในเซสชันรองรับข้อความ รูปภาพ และไฟล์เมื่อทั้งสองฝ่ายรองรับ ให้คงการเชื่อมต่อเซสชันไว้ และตรวจสอบตัวเลือกนี้ทั้งสองฝั่งหากคัดลอกและวางไม่ได้
  6. การเปลี่ยนการตั้งค่าสตรีมของอุปกรณ์ส่วนใหญ่มีผลหลังเชื่อมต่อใหม่ «การปรับแต่งเดสก์ท็อปอย่างละเอียด» มีผลระหว่างเซสชัน ส่วนรูปลักษณ์และปุ่มลัดหน้าต่างทั้งระบบมีผลทันที

คุณภาพภาพ เสียง และการใช้ข้อมูล

  1. «การตั้งค่าการสตรีมขั้นสูง» มีโหมดภาพ «อัตโนมัติ», «ชัดเจน», «เรียบ», «ประหยัดข้อมูล» และ «กำหนดเอง» โดย «อัตโนมัติ» จะเลือกแบนด์วิดท์ตามความละเอียดและปรับตามเครือข่าย
  2. «ประหยัดข้อมูล» ใช้ 30 fps และจำกัดวิดีโอที่ 5 Mbps สวิตช์ประหยัดข้อมูลในแถบด้านบนมีผลกับทุกอุปกรณ์ โดยยังมีปริมาณข้อมูลเสียงและโปรโตคอลเพิ่มเติม
  3. อัตราเฟรมและแบนด์วิดท์ที่สูงขึ้นต้องใช้ความสามารถของเครือข่ายและการประมวลผลมากขึ้น หากภาพเคลื่อนไหวกระตุกหรืออินพุตล่าช้า ให้ลดค่าทั้งสองและตรวจสอบสถิติการสตรีมก่อนเพิ่มคุณภาพ
  4. ตัวเลือกเสียงมีทั้งปิดเสียงเมื่อ DeskPort เสียโฟกัสและเล่นเสียงบนโฮสต์ด้วย หากไม่มีเสียง ให้ตรวจสอบสวิตช์ «เสียง» ของอุปกรณ์ การปิดเสียงเมื่อเสียโฟกัส และเอาต์พุตเสียงของคอมพิวเตอร์ทั้งสองเครื่อง

เชื่อมต่อจากเบราว์เซอร์

  1. บนคอมพิวเตอร์โฮสต์ ให้เปิด การแบ่งปัน → การเข้าถึงเบราว์เซอร์ แล้วสแกนหรือเปิด URL ที่แสดงบนอุปกรณ์อีกเครื่อง เริ่มแชร์ก่อนเชื่อมต่อ
  2. ป้อนรหัสหกหลักที่แสดงบนโฮสต์หรือในแอปยืนยันตัวตนของคุณ รหัสจะเปลี่ยนทุก 30 วินาที อุปกรณ์ที่ระบบระบุว่าลงชื่อเข้าใช้บัญชี Tailscale เดียวกันสามารถเชื่อมต่อได้โดยไม่ต้องใช้รหัส
  3. อุปกรณ์ที่เชื่อมต่อต้องเชื่อถือใบรับรอง HTTPS ภายในเครื่องของโฮสต์ ตรวจสอบ URL และใบรับรองให้ตรงกับโฮสต์ของคุณเองก่อนเชื่อถือ
  4. «จำเบราว์เซอร์นี้เป็นเวลา 7 วัน» จะข้ามการขอรหัสครั้งถัดไปในเบราว์เซอร์นั้น หากต้องการเพิกถอนสิทธิ์ ให้ลบเบราว์เซอร์ที่จับคู่ไว้จาก «การแบ่งปัน» เก็บ QR ยืนยันตัวตนเป็นความลับ การรีเซ็ตคีย์ลับจะทำให้ตัวสร้างรหัสยืนยันเดิมใช้ไม่ได้

การตั้งค่า ความเป็นส่วนตัว และข้อเสนอแนะ

  1. «การตั้งค่า» ควบคุมธีม สีเน้น ภาษา การแสดงการใช้ข้อมูลในแถบด้านบน และปุ่มลัดหน้าต่างทั้งระบบของคอมพิวเตอร์เครื่องนี้ ส่วน «การตั้งค่าอุปกรณ์» ควบคุมการเชื่อมต่อที่บันทึกไว้แต่ละรายการแยกกัน
  2. บันทึกการวินิจฉัยปิดอยู่ตามค่าเริ่มต้น เปิดใน การตั้งค่า → การวินิจฉัยและข้อเสนอแนะ ก่อนทำให้ปัญหาเกิดซ้ำ บันทึกจะอยู่บนคอมพิวเตอร์เครื่องนี้จนกว่าคุณจะเลือกแชร์
  3. «รายงานปัญหา» จะสร้าง ZIP และเปิดแบบร่างรายงานปัญหาใน GitHub ไม่มีการอัปโหลดหรือส่งโดยอัตโนมัติ ตรวจสอบไฟล์เก็บถาวรและอธิบายขั้นตอน ระบบ และพฤติกรรมที่คาดหวังก่อนแนบกับรายงานปัญหาสาธารณะ
  4. การปิดการวินิจฉัยจะหยุดบันทึกข้อมูลใหม่ «ล้างการวินิจฉัยที่บันทึกไว้» จะลบบันทึกเดิมและ ZIP ที่สร้างไว้ «ความเป็นส่วนตัว» และ «ใบอนุญาต» ใน «การตั้งค่า» อธิบายข้อมูลที่บันทึกและซอฟต์แวร์ที่รวมมาด้วย

เมื่อมีสิ่งผิดปกติเกิดขึ้น

  1. อุปกรณ์ที่แสดงเป็นออฟไลน์มักจะอยู่ในโหมดสลีป บนเครือข่ายอื่น หรือไม่แชร์
  2. รีเฟรชในแถบด้านบนจะตรวจสอบอุปกรณ์ที่บันทึกไว้ทุกเครื่องอีกครั้ง
  3. รายงานปัญหาในการตั้งค่าจะรวบรวมไฟล์บันทึกที่คุณสามารถแนบไปกับปัญหาได้ ตรวจสอบก่อนแชร์
  4. หากอุปกรณ์ยังออฟไลน์อยู่ ให้ยืนยันว่าไม่ได้อยู่ในโหมดสลีป เปิดการแชร์อยู่ และเข้าถึงที่อยู่ที่บันทึกไว้ได้ ตรวจสอบความพร้อมและไฟร์วอลล์ของโฮสต์ก่อนลองอีกครั้ง การรีเฟรชไม่สามารถปลุกโฮสต์ได้ทุกเครื่องหรือแก้เส้นทางเครือข่ายได้
  5. หากภาพเป็นสีดำ ให้ตรวจสอบสิทธิ์บันทึกหน้าจอและจอของโฮสต์ที่เลือก หากควบคุมไม่ได้ ให้ตรวจสอบการช่วยการเข้าถึง สวิตช์ «ป้อนข้อมูล» ของอุปกรณ์ และว่าหน้าต่างแสดงผลมีโฟกัสหรือไม่
  6. หากปุ่มลัดหน้าต่างทั้งระบบหยุดทำงาน ให้ตรวจสอบสวิตช์ใน «การตั้งค่า» สิทธิ์ปุ่มลัดของเดสก์ท็อป และการซ้ำกับแอปอื่น ปิดแล้วเปิดใหม่เพื่อขอลงทะเบียนอีกครั้ง คุณยังใช้ถาดระบบและ «อุปกรณ์» ได้
