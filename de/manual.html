Was DeskPort ist

  1. DeskPort gibt einen Computer frei, damit Ihre anderen Geräte seinen Desktop verwenden können.
  2. Der verwendete Computer ist der Host, das Gerät vor Ihnen der Client. Ein Computer kann beides sein.
  3. Geräte werden einmal miteinander verbunden. Der Zugriff wird auf dem Host genehmigt und kann dort widerrufen werden.
  4. DeskPort speichert Geräte und Einstellungen lokal auf diesem Gerät. Ein DeskPort-Konto ist nicht erforderlich.

Diesen Computer freigeben

  1. Öffnen Sie „Freigabe“ in der oberen Leiste und wählen Sie „Freigabe starten“.
  2. Erlauben Sie Bildschirmaufnahme und Bedienungshilfen, wenn Sie gefragt werden. Die Freigabe startet auch ohne, aber Bild oder Eingabe funktionieren dann nicht.
  3. Ein Punkt unter dem Freigabesymbol zeigt, dass dieser Computer gerade freigegeben ist.
  4. Prüfen Sie unter macOS in den Systemeinstellungen „Bildschirmaufnahme“ und „Bedienungshilfen“, falls das Bild leer bleibt oder die Fernsteuerung nicht funktioniert. „Freigabe“ zeigt Berechtigungs- und Bereitschaftsprüfungen an.
  5. Blenden Sie das DeskPort-Fenster aus, um im Hintergrund weiter freizugeben. Verwenden Sie „Freigabe beenden“, wenn dieser Computer keine Desktop-Verbindungen mehr annehmen soll.

Mit einem Computer verbinden

  1. Geräte im selben Netzwerk erscheinen von selbst in der Geräteliste.
  2. Für einen Computer in einem anderen Netzwerk tippen Sie auf der Hinzufügen-Karte auf „Gerät hinzufügen“ und geben seine Adresse ein.
  3. Beim ersten Auswählen eines Geräts wird der Host um Zugriff gebeten; genehmigen Sie die Anfrage dort.
  4. Ist bereits ein anderes Gerät verbunden, werden Sie gefragt, ob Sie übernehmen möchten. Die Übernahme trennt dieses Gerät.
  5. Für ein anderes Netzwerk benötigen beide Geräte weiterhin eine erreichbare Route, etwa Ihr eigenes VPN- oder Tailscale-Netzwerk. Das Hinzufügen einer Adresse erstellt diese Route nicht.
  6. „Adresse ändern“ im Menü einer Gerätekarte nimmt mehrere Adressen an, eine pro Zeile, alle auf dem gekoppelten Port. DeskPort probiert sie gleichzeitig und verwendet die erste antwortende Adresse in der Liste; tragen Sie daher zuerst eine LAN-Adresse und danach eine Domain oder VPN-Adresse ein. Sie können sie während einer Verbindung ändern: Offene Sitzungen behalten ihre aktuelle Adresse, die nächste Verbindung verwendet die neue Liste.
  7. Sunshine und Hosts ohne DeskPort-Bindung verwenden „Klassischen Host hinzufügen“ und die PIN-Kopplung. Lassen Sie den Host geöffnet, um die PIN zu bestätigen.
  8. Entfernen Sie den gespeicherten Zugriff auf dem freigebenden Computer, um die Steuerung zu entziehen. Das Entfernen einer Karte aus „Geräte“ und das Entziehen des Zugriffs sind getrennte Vorgänge; entfernen Sie beim Entkoppeln zweier Computer beide Richtungen.

Die Geräteliste ordnen

  1. „Bearbeiten“ in der oberen Leiste startet den Bearbeitungsmodus; ziehen Sie Karten, um sie neu anzuordnen.
  2. Ziehen Sie ein Gerät auf ein anderes, um sie zu gruppieren – wie Ordner auf dem Startbildschirm eines Telefons.
  3. „Alias festlegen“ im Kartenmenü benennt ein Gerät nur auf diesem Gerät um.
  4. Aktualisieren prüft gespeicherte Geräte erneut und sucht nach neuen.
  5. Öffnen Sie das Menü einer Gerätekarte für Status, Adresse und Verbindungsaktionen. „Adresse ändern“ aktualisiert den gespeicherten Verbindungseintrag; ein Alias benennt den entfernten Computer nicht um.

Fenster und Hintergrundsitzungen

  1. Auf dem Desktop bleibt eine Sitzung beim Schließen oder Ausblenden des Viewers im Hintergrund verbunden. „Trennen“ beendet diese Verbindung; „Beenden“ schließt DeskPort.
  2. Holen Sie den aktiven Desktop über das Tray-Menü oder die Geräteliste zurück. Bei mehreren Sitzungen wählen Sie die gewünschte im Sitzungsmenü aus.
  3. Beim Ausblenden eines Viewers oder beim Fokuswechsel werden gehaltene entfernte Tasten und Maustasten losgelassen. Der lokale Computer bleibt nutzbar, während die entfernte Sitzung verbunden bleibt.
  4. Verwenden Sie „Erneut verbinden“ im Gerätemenü, wenn eine Sitzung neu aufgebaut werden muss oder gespeicherte Streaming-Einstellungen übernommen werden sollen.

Tastenkombinationen auf dem Desktop

  1. Meta + ' blendet DeskPort ein oder aus: Verwenden Sie Command + ' unter macOS, Windows + ' unter Windows oder Super + ' unter Linux. Lassen Sie die Tasten zum Auslösen los. Dadurch wird die ausgewählte Sitzung oder ohne aktive Sitzung „Geräte“ geöffnet.
  2. „Einstellungen → Tastenkombinationen → Globales Fenster-Tastenkürzel“ ist standardmäßig aktiviert. Beim Ausschalten wird die Systembelegung sofort freigegeben und der Viewer-Fallback deaktiviert. Diese Auswahl wird auf diesem Computer gespeichert.
  3. Klicken Sie unter „Einstellungen → Tastenkombinationen“ in der Zeile „Globales Fenster-Tastenkürzel“ auf die aktuelle Tastenkombination. Drücken Sie eine Kombination oder nutzen Sie „Tasten auswählen“ und speichern Sie sie. Die neue Belegung gilt sofort auf diesem Computer. „Standard wiederherstellen“ setzt sie auf Meta + Apostroph zurück (Command + Apostroph unter macOS). „Abbrechen“ behält die bisherige Belegung bei. Während der Aufnahme ist das globale Tastenkürzel pausiert.
  4. KDE Plasma weist Meta+1–9 häufig Einträgen der Fensterleiste zu. Reagiert die Aufnahme nicht, geben Sie die Kombination über „Tasten auswählen“ ein. Beim Speichern bittet der Desktop Sie möglicherweise, einen Konflikt zu lösen; Sie können auch eine andere Kombination wählen.
  5. Unter Wayland fragt der Desktop möglicherweise nach einer Berechtigung und lässt Sie die Belegung wählen. Das vom Desktop gewählte Tastenkürzel hat Vorrang. Wird die Registrierung abgelehnt, nicht unterstützt oder bereits verwendet, nutzen Sie das Tray oder die Geräteliste; DeskPort überschreibt keine Belegung einer anderen App.
  6. Während einer Desktop-Verbindung gibt Ctrl+Alt+Shift+Z die entfernte Eingabe frei oder fängt sie wieder ein; X schaltet das Vollbild um; N wechselt zum nächsten verbundenen Desktop. Halten Sie für jeden Buchstaben Ctrl+Alt+Shift gedrückt.
  7. Ctrl+Alt+Shift+S blendet die Streaming-Statistiken ein oder aus; D minimiert den Viewer; M wechselt den Zeigermodus; C schaltet den lokalen Zeiger im Desktop-Modus um; L schaltet die Zeigerbegrenzung um.
  8. Ctrl+Alt+Shift+V sendet Text aus der lokalen Zwischenablage als getippten Text. Q verlässt zuerst das Vollbild; erneutes Drücken von Ctrl+Alt+Shift+Q im Fenster trennt die Verbindung.

Vollbild

  1. Auf dem Desktop wählen Sie unter „Geräteeinstellungen → Erweiterte Streaming-Einstellungen → Verbindungsfenster“ für die nächste Verbindung zwischen „Fenster“, „Vollbild“ oder „Randloses Vollbild“.
  2. Auf einem Computer schaltet Strg+Alt+Umschalt+X während einer Verbindung das Vollbild ein und aus; auf Telefon oder Tablet holt es die schwebende Taste zurück.
  3. Auf Telefonen und Tablets nutzt der entfernte Desktop immer den ganzen Bildschirm. Tippen Sie auf die schwebende Taste für die Tastatur, halten Sie sie für das Menü.
  4. Der Host kann ein verbundenes Gerät bitten, das Vollbild zu verlassen, erzwingt es aber nie.

Bild und virtueller Bildschirm

  1. Der entfernte Desktop folgt Ihrer Fenstergröße; wenn Sie das Fenster ändern, ändert sich auch der Desktop.
  2. „Virtueller Bildschirm“ legt fest, was mit den Bildschirmen des Hosts während der Verbindung geschieht.
  3. Die Desktop-Feinabstimmung macht alles auf dem entfernten Desktop größer oder kleiner.
  4. Diese Einstellungen werden pro Gerät gespeichert.
  5. „An Fenster anpassen“ nutzt die darstellbaren Pixel des Viewers. Deaktivieren Sie die Option, um stattdessen die gespeicherte Auflösung zu verwenden; verfügbare Desktop-Größen und Skalierung hängen weiterhin vom Host ab.
  6. „Desktop-Feinabstimmung“: 1.5 vergrößert Bedienelemente, 0.5 zeigt mehr Inhalt. Die Einstellung wirkt sofort während einer Verbindung. Eine Mindestgröße des Hosts kann weiteres Vergrößern begrenzen; versuchen Sie ein größeres Fenster oder Vollbild.
  7. „Haupt + Spiegeln“ spiegelt den entfernten Arbeitsbereich, „Nur Hauptbildschirm“ schaltet andere Bildschirme des Hosts aus und „Erweitert“ fügt einen Arbeitsbereich hinzu. Die Unterstützung hängt vom Host ab; nach Sitzungsende wird das vorherige Bildschirmlayout wiederhergestellt.

Tastatur, Zeiger und Zwischenablage

  1. „Geräteeinstellungen → Eingabe“ legt fest, ob Tastatur-, Zeiger- und Controller-Ereignisse gesendet werden. Schalten Sie dies für eine reine Ansicht aus; „Ton“ steuert den Audioempfang separat.
  2. „Erweiterte Streaming-Einstellungen → Tastatur und Zeiger“ enthält Zeigermodus, Scrollrichtung, Weiterleitung von System-Tastenkürzeln und das Teilen der Sitzungs-Zwischenablage.
  3. Auf einem Mac-Host wird Super / Windows auf Command und Alt auf Option abgebildet. Das Betriebssystem reserviert möglicherweise einige Tastenkürzel; mit Ctrl+Alt+Shift+Z geben Sie die Eingabe an den lokalen Computer zurück.
  4. „Lokale Eingabemethode verwenden“ ist standardmäßig deaktiviert. Aktivieren Sie die Option pro Gerät und verbinden Sie sich erneut, um mit dem IME dieses Computers zu schreiben. Vorschläge erscheinen oben links statt am entfernten Textcursor; nutzen Sie bei Bedarf oder für Spiele das entfernte IME oder physische Tasten.
  5. Das Teilen der Sitzungs-Zwischenablage unterstützt Text, Bilder und Dateien, sofern beide Seiten dies unterstützen. Lassen Sie die Sitzung verbunden und prüfen Sie diese Option auf beiden Seiten, falls Kopieren und Einfügen fehlschlägt.
  6. Die meisten Streaming-Änderungen eines Geräts gelten nach einem erneuten Verbinden. Die „Desktop-Feinabstimmung“ wirkt während der Sitzung; Darstellung und das globale Fenster-Tastenkürzel gelten sofort.

Bildqualität, Ton und Datenverbrauch

  1. „Erweiterte Streaming-Einstellungen“ bietet die Bildmodi „Automatisch“, „Scharf“, „Flüssig“, „Daten sparen“ und „Eigene“. „Automatisch“ wählt die Bandbreite anhand der Auflösung und passt sich dem Netzwerk an.
  2. „Daten sparen“ nutzt 30 fps und ein Videolimit von 5 Mbps. Der Datensparschalter in der oberen Leiste gilt für alle Geräte; Audio- und Protokolldaten kommen hinzu.
  3. Höhere Bildraten und Bandbreiten erfordern mehr Netzwerk- und Rechenleistung. Wenn Bewegungen ruckeln oder Eingaben verzögert wirken, verringern Sie diese Werte und prüfen Sie die Streaming-Statistiken, bevor Sie die Qualität erhöhen.
  4. Zu den Tonoptionen gehören das Stummschalten bei Fokusverlust von DeskPort sowie die gleichzeitige Audiowiedergabe auf dem Host. Fehlt der Ton, prüfen Sie den Schalter „Ton“ des Geräts, die Stummschaltung bei Fokusverlust und die Audioausgänge beider Computer.

Über einen Browser verbinden

  1. Öffnen Sie auf dem Desktop-Host „Freigabe → Browserzugriff“ und scannen oder öffnen Sie die angezeigte URL auf dem anderen Gerät. Starten Sie vor dem Verbinden die Freigabe.
  2. Geben Sie den sechsstelligen Code ein, der auf dem Host oder in Ihrer Authenticator-App angezeigt wird; er ändert sich alle 30 Sekunden. Geräte, die als im selben Tailscale-Konto angemeldet erkannt werden, können sich ohne Code verbinden.
  3. Das verbindende Gerät muss dem lokalen HTTPS-Zertifikat des Hosts vertrauen. Gleichen Sie URL und Zertifikat mit Ihrem eigenen Host ab, bevor Sie ihm vertrauen.
  4. „Diesen Browser 7 Tage merken“ überspringt spätere Codeabfragen in diesem Browser. Entfernen Sie einen gekoppelten Browser unter „Freigabe“, um ihm den Zugriff zu entziehen. Halten Sie den Authenticator-QR-Code geheim; das Zurücksetzen des Geheimnisses macht bestehende Authenticatoren ungültig.

Einstellungen, Datenschutz und Feedback

  1. „Einstellungen“ steuert Design, Akzentfarbe, Sprache, Datenverbrauchsanzeige in der oberen Leiste und das globale Fenster-Tastenkürzel dieses Computers. „Geräteeinstellungen“ steuert jede gespeicherte Verbindung einzeln.
  2. Diagnoseprotokolle sind standardmäßig deaktiviert. Aktivieren Sie sie unter „Einstellungen → Diagnose und Feedback“, bevor Sie ein Problem nachstellen. Sie bleiben auf diesem Computer, bis Sie sie teilen.
  3. „Problem melden“ erstellt ein ZIP-Archiv und öffnet einen GitHub-Issue-Entwurf. Es wird nichts automatisch hochgeladen oder abgesendet. Prüfen Sie das Archiv und beschreiben Sie Schritte, Systeme und erwartetes Verhalten, bevor Sie es an ein öffentliches Issue anhängen.
  4. Das Ausschalten der Diagnose beendet neue Aufzeichnungen. „Gespeicherte Diagnosedaten löschen“ entfernt vorhandene Protokolle und das erzeugte ZIP-Archiv. „Datenschutz“ und „Lizenzen“ in den „Einstellungen“ erläutern aufgezeichnete Daten und enthaltene Software.

Wenn etwas nicht funktioniert

  1. Ein als offline angezeigtes Gerät schläft meist, ist in einem anderen Netzwerk oder gibt nicht frei.
  2. Aktualisieren in der oberen Leiste prüft jedes gespeicherte Gerät erneut.
  3. „Problem melden“ in den Einstellungen erstellt ein Protokollarchiv, das Sie an ein Issue anhängen können. Prüfen Sie es vor dem Teilen.
  4. Bleibt ein Gerät offline, stellen Sie sicher, dass es wach ist, die Freigabe läuft und die gespeicherte Adresse erreichbar ist. Prüfen Sie vor einem neuen Versuch Bereitschaft und Firewall des Hosts; „Aktualisieren“ kann nicht jeden Host aufwecken oder eine Netzwerkroute reparieren.
  5. Prüfen Sie bei schwarzem Bild die Berechtigung für die Bildschirmaufnahme und den gewählten Host-Bildschirm. Fehlt die Steuerung, prüfen Sie die Bedienungshilfen, den Schalter „Eingabe“ des Geräts und ob der Viewer den Fokus hat.
  6. Wenn das globale Fenster-Tastenkürzel nicht mehr funktioniert, prüfen Sie den Schalter in den „Einstellungen“, die Tastenkürzel-Berechtigung des Desktops sowie Konflikte mit anderen Apps. Schalten Sie es aus und wieder ein, um die Registrierung erneut anzufordern; Tray und „Geräte“ bleiben verfügbar.
