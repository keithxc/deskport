Qué es DeskPort

  1. DeskPort comparte un ordenador para que tus otros dispositivos puedan usar su escritorio.
  2. El ordenador que se usa es el host y el dispositivo que tienes delante es el cliente. Un ordenador puede ser ambos.
  3. Los dispositivos se vinculan una sola vez. El acceso se aprueba en el host y se puede retirar allí.
  4. DeskPort keeps saved devices and settings on this device. It does not require a DeskPort account.

Compartir este ordenador

  1. Abre Compartir en la barra superior y elige Empezar a compartir.
  2. Concede la grabación de pantalla y la accesibilidad cuando se pidan. Se puede compartir sin ellos, pero la imagen o la entrada no funcionarán.
  3. Un punto bajo el icono de compartir indica que este ordenador se está compartiendo.
  4. On macOS, check Screen Recording and Accessibility in System Settings if the picture is blank or remote control does not work. Sharing shows permission and readiness checks.
  5. Hide the DeskPort window to keep sharing in the background. Use Stop sharing when this computer should no longer accept desktop connections.

Conectarse a un ordenador

  1. Los dispositivos de la misma red aparecen solos en la lista.
  2. Para un ordenador de otra red, usa Añadir dispositivo en la tarjeta de añadir e introduce su dirección.
  3. La primera vez que eliges un dispositivo se pide acceso al host; apruébalo allí.
  4. Si ya hay otro dispositivo conectado, se te pregunta si quieres tomar el control. Hacerlo desconecta ese dispositivo.
  5. For another network, both devices still need a reachable route, such as your own VPN or Tailscale network. Adding an address does not create that route.
  6. Cambiar dirección en el menú de la tarjeta de un dispositivo acepta varias direcciones, una por línea, todas en el puerto de emparejamiento. DeskPort las prueba a la vez y usa la primera de la lista que responda, así que pon primero una dirección de la red local y después un dominio o una dirección VPN. Puedes cambiarlas durante una conexión: las sesiones abiertas conservan su dirección actual y la siguiente conexión usa la lista nueva.
  7. Sunshine and hosts without DeskPort binding use Add a legacy host and PIN pairing. Keep the host open to approve the PIN.
  8. Remove saved access on the Sharing computer to revoke control. Removing a card from Devices and revoking access are separate actions; remove both directions when unbinding two computers.

Organizar la lista de dispositivos

  1. Editar en la barra superior activa el modo de edición; arrastra las tarjetas para reordenarlas.
  2. Suelta un dispositivo sobre otro para agruparlos, como las carpetas en la pantalla de inicio de un móvil.
  3. Establecer alias en el menú de la tarjeta cambia el nombre solo en este dispositivo.
  4. Actualizar vuelve a comprobar los dispositivos guardados y busca otros nuevos.
  5. Open a device card's menu for its status, address and connection actions. Change address updates the saved connection entry; an alias does not rename the remote computer.

Windows and background sessions

  1. On desktop, closing or hiding a viewer keeps its session connected in the background. Disconnect ends that connection; Quit exits DeskPort.
  2. Recall the active desktop from the tray menu or device list. With several sessions, select the one you want from the session menu.
  3. Hiding a viewer or moving focus away releases held remote keys and buttons. The local computer remains usable while the remote session stays connected.
  4. Use Reconnect in the device menu if a session needs a fresh connection or to apply saved streaming settings.

Keyboard shortcuts on desktop

  1. Meta + ' shows or hides DeskPort: use Command + ' on macOS, Windows + ' on Windows, or Super + ' on Linux. Release the keys to trigger it. It recalls the selected session, or Devices when no session is connected.
  2. Settings → Keyboard shortcuts → Global window shortcut is on by default. Turning it off releases the system binding and disables the viewer fallback immediately. This choice is saved on this computer.
  3. In Settings → Keyboard shortcuts, click the current key combination on the Global window shortcut row. Press a combination or use Choose keys, then save it. The new binding applies immediately on this computer. Restore default returns to Meta + apostrophe (Command + apostrophe on macOS). Cancel keeps the previous binding. While recording, the global shortcut is paused.
  4. KDE Plasma commonly assigns Meta+1–9 to task-manager entries. If recording does not respond, use Choose keys to enter the combination. The desktop may ask you to resolve a conflict when saving; you can also choose another combination.
  5. On Wayland, the desktop may ask permission and let you choose the binding. The desktop's chosen shortcut takes precedence. If registration is denied, unsupported or already in use, use the tray or device list; DeskPort does not replace another app's binding.
  6. During a desktop connection, Ctrl+Alt+Shift+Z releases or recaptures remote input; X toggles full screen; N switches to the next connected desktop. Hold Ctrl+Alt+Shift for each letter.
  7. Ctrl+Alt+Shift+S toggles streaming statistics; D minimizes the viewer; M switches pointer mode; C toggles the local pointer in desktop mode; L toggles pointer confinement.
  8. Ctrl+Alt+Shift+V sends local clipboard text as typed text. Q leaves full screen first; pressing Ctrl+Alt+Shift+Q again from the window disconnects.

Pantalla completa

  1. On desktop, Device settings → Advanced streaming settings → Connection window chooses Window, Full screen or Borderless full screen for the next connection.
  2. En un ordenador, Ctrl+Alt+Mayús+X activa y desactiva la pantalla completa durante una conexión; en un móvil o tableta, recupera el botón flotante.
  3. En móviles y tabletas, el escritorio remoto ocupa siempre toda la pantalla. Toca el botón flotante para el teclado y mantenlo pulsado para el menú.
  4. El host puede pedir a un dispositivo conectado que salga de la pantalla completa, pero nunca la impone.

Imagen y pantalla virtual

  1. El escritorio remoto sigue el tamaño de tu ventana: al cambiarla, cambia también el escritorio remoto.
  2. Pantalla virtual decide qué pasa con las pantallas del host mientras estás conectado.
  3. El ajuste fino del escritorio hace más grande o más pequeño todo lo del escritorio remoto.
  4. Estos ajustes se guardan por dispositivo.
  5. Fit to window uses the viewer's drawable pixels. Turn it off to use the saved resolution instead; available desktop sizes and scaling still depend on the host.
  6. Desktop fine tuning: 1.5 makes controls larger; 0.5 fits more content. It takes effect during a connection. A host minimum size can limit further enlargement; try a larger window or full screen.
  7. Main + mirror mirrors the remote workspace, Main only turns off other host screens, and Extended adds a workspace. Support varies by host; the previous screen layout is restored when the session ends.

Keyboard, pointer and clipboard

  1. Device settings → Input controls whether keyboard, pointer and controller events are sent. Turn it off for viewing only; Sound separately controls received audio.
  2. Advanced streaming settings → Keyboard & pointer contains pointer mode, scrolling direction, system shortcut forwarding and session clipboard sharing.
  3. On a Mac host, Super / Windows maps to Command and Alt maps to Option. The operating system may reserve some shortcuts; use Ctrl+Alt+Shift+Z to return input to the local computer.
  4. Use the local input method is off by default. Enable it per device and reconnect to compose with this computer's IME. Candidates appear near the top left, not at the remote caret; use the remote IME or physical keys for games when needed.
  5. Session clipboard sharing supports text, images and files when both peers support them. Keep the session connected and check this option on both ends if copy and paste fails.
  6. Most device streaming changes apply after reconnecting. Desktop fine tuning applies during the session; appearance and the global window shortcut apply immediately.

Picture quality, sound and data usage

  1. Advanced streaming settings offers Automatic, Clear, Smooth, Save data and Custom picture modes. Automatic chooses bandwidth from the resolution and adapts to the network.
  2. Save data uses 30 fps and a 5 Mbps video limit. The data saver switch in the top bar applies to every device; audio and protocol traffic are additional.
  3. Higher frame rates and bandwidth need more network and processing capacity. If motion stutters or input feels delayed, lower them and check streaming statistics before increasing quality.
  4. Sound options include muting when DeskPort loses focus and also playing audio on the host. If sound is missing, check the device's Sound switch, focus mute and both computers' audio outputs.

Connect from a browser

  1. On the desktop host, open Sharing → Browser access, then scan or open the displayed URL on the other device. Start sharing before connecting.
  2. Enter the six-digit code shown on the host or in your authenticator app; it changes every 30 seconds. Devices recognized as signed in to the same Tailscale account can connect without the code.
  3. The connecting device must trust the host's local HTTPS certificate. Check the URL and certificate against your own host before trusting it.
  4. Remember this browser for 7 days skips later code prompts on that browser. Remove a paired browser from Sharing to revoke it. Keep the authenticator QR private; resetting its secret invalidates existing authenticators.

Settings, privacy and feedback

  1. Settings controls this computer's theme, accent color, language, top-bar data usage and global window shortcut. Device settings controls each saved connection separately.
  2. Diagnostic logs are off by default. Enable them in Settings → Diagnostics and feedback before reproducing a problem. They stay on this computer until you choose to share them.
  3. Report a problem creates a ZIP and opens a draft GitHub issue. Nothing is uploaded or submitted automatically. Review the archive and describe the steps, systems and expected behavior before attaching it to a public issue.
  4. Turning diagnostics off stops new recording. Clear saved diagnostics removes existing logs and the generated ZIP. Privacy and Licenses in Settings explain recorded data and bundled software.

Si algo falla

  1. Un dispositivo que aparece sin conexión suele estar en reposo, en otra red o sin compartir.
  2. Actualizar en la barra superior vuelve a comprobar cada dispositivo guardado.
  3. Informar de un problema, en Ajustes, crea un archivo de registros que puedes adjuntar a una incidencia. Revísalo antes de compartirlo.
  4. If a device stays offline, confirm it is awake, sharing is on and its saved address is reachable. Check the host's readiness and firewall before retrying; Refresh cannot wake every host or repair a network route.
  5. For a black picture, check screen recording permission and the selected host display. For missing control, check Accessibility, the device's Input switch and whether the viewer has focus.
  6. If the global window shortcut stops working, check its Settings switch, the desktop's shortcut permission and conflicts with other apps. Turn it off and on to request registration again; the tray and Devices remain available.
