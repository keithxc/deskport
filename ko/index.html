iPad에서 내 데스크톱을.

iPad나 iPhone에서 터치, 키보드, 포인터로 내 컴퓨터를 사용하세요. DeskPort는 데스크톱 앱과 작업 공간을 모바일 화면으로 가져옵니다.

먼저 컴퓨터에 DeskPort를 설치하세요

데스크톱 앱은 무료 오픈 소스입니다. 호스트 기능이 있는 DeskPort 패키지를 컴퓨터에 설치하고 공유를 켠 다음 iPad/iPhone 앱으로 연결하세요.

GitHub에서 컴퓨터용 DeskPort 0.7.2 다운로드 →
macOS Apple Silicon · Linux x86_64 · Windows x64 — 뷰어 및 호스트. Linux Flatpak은 뷰어 전용입니다. Android 클라이언트는 비공개 테스트 중입니다(자세히).

App Store의 DeskPort (iPad & iPhone) · 설정 가이드 →

데스크톱 작업을 위해 설계

  • 저장한 컴퓨터마다 화면, 오디오, 입력 설정을 따로 저장.
  • 직접 터치 또는 트랙패드 모드, 보조 키와 탐색 키가 있는 화면 키보드.
  • 세로 및 가로 보기 지원, DeskPort 호스트가 지원하는 데스크톱 크기 옵션.
  • 연결 진행 상황, 세션 제어, 사용 중인 세션을 넘겨받기 전 확인.

iPad/iPhone 앱에는 DeskPort 데스크톱 호스트가 필요합니다. 수정되지 않은 단독 Sunshine 호스트는 지원하지 않습니다. DeskPort 계정이나 클라우드 컴퓨터는 포함되지 않습니다. 사용 가능한 화면 및 입력 기능은 컴퓨터, 호스트 패키지, 연결된 기기에 따라 다릅니다.
