버전 노트

빌드 14는 서명된 SDK 수정 사항을 TestFlight 및 App Store 심사를 위해 버전 1.5로 다시 패키징한 것입니다.

빌드 13(버전 1.3)은 소스에서 빌드한 OpenSSL XCFramework에 서명하고, 아카이브 시 SDK 출처 서명 메타데이터를 검증합니다. App Store 처리 및 심사는 별개입니다.

빌드 11에는 반응형 기기 카드, 연결 및 입력 개선, 소스에서 빌드한 OpenSSL과 해당 디버그 심볼이 포함됩니다. 전체 소스 다운로드는 링크된 소스 전용 GitHub 릴리스에서 제공되며, App Store 심사 상태는 별개입니다.

빌드 7은 빌드 6을 App Store 출시용 버전 1.1로 다시 패키징한 것으로, 앱 동작 변경은 없습니다.

빌드 6은 데스크톱 바로 들어가기, 기기별 데스크톱 조정, 확인을 거치는 세션 넘겨받기(넘겨준 클라이언트에 구체적인 설명 표시)를 추가했습니다.

빌드 5는 공유 작업 공간 코어와 기기별 가상 화면 정책을 추가했으며, 엄격한 기능 협상과 작은 기기에서도 읽기 쉬운 설정을 제공합니다.

빌드 4는 네이티브 Sunshine 서비스를 걸러내고 DeskPort 승인 바인딩을 유지하며, 기존 바인딩을 제거하지 않고 저장된 도메인/IP를 편집할 수 있게 했습니다. 검색 전송 방식은 변경되지 않았습니다.

빌드 3은 오프라인 의존성 고지 전체를 추가하고 이미 사용 중인 OpenSSL 패키지 버전을 고정했습니다. 연결 인터페이스는 빌드 2와 같습니다. 빌드 2는 업스트림의 자동 공인 주소 검색을 제거했습니다. 빌드 1 소스는 최초 TestFlight 빌드 수령자를 위해 계속 제공됩니다.

어떠한 보증도 제공하지 않습니다. Apple SDK와 서명 자격 증명은 빌드하는 사람이 준비해야 합니다. DeskPort는 제3자 미디어 카탈로그나 구독 콘텐츠 접근을 제공하지 않습니다. 접근 권한이 있는 컴퓨터와 콘텐츠만 사용하세요.

소스 다운로드 문제는 GitHub Issues로 신고하세요. 자격 증명이나 개인적인 내용은 올리지 마세요.
