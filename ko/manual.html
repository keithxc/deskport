DeskPort란

  1. DeskPort는 컴퓨터 한 대를 공유해 다른 기기에서 그 데스크톱을 사용할 수 있게 합니다.
  2. 사용되는 컴퓨터가 호스트, 앞에서 조작하는 기기가 클라이언트입니다. 한 컴퓨터가 둘 다일 수도 있습니다.
  3. 기기끼리는 한 번만 바인딩하면 됩니다. 접근 권한은 호스트에서 승인하고 호스트에서 철회할 수 있습니다.
  4. DeskPort는 저장된 기기와 설정을 이 기기에 보관합니다. DeskPort 계정은 필요하지 않습니다.

이 컴퓨터 공유하기

  1. 상단 바에서 공유를 열고 공유 시작을 선택합니다.
  2. 요청되면 화면 기록과 손쉬운 사용 권한을 허용합니다. 허용하지 않아도 공유는 시작되지만 화면이나 입력이 작동하지 않습니다.
  3. 공유 아이콘 아래의 점은 이 컴퓨터가 공유 중이라는 뜻입니다.
  4. macOS에서 화면이 나오지 않거나 원격 제어가 작동하지 않으면 시스템 설정에서 화면 기록과 손쉬운 사용 권한을 확인하세요. 공유에서 권한과 준비 상태의 점검 결과를 볼 수 있습니다.
  5. DeskPort 창을 숨기면 백그라운드에서 공유를 계속할 수 있습니다. 이 컴퓨터에 대한 데스크톱 연결을 더 이상 허용하지 않으려면 공유 중지를 사용하세요.

컴퓨터에 연결하기

  1. 같은 네트워크의 기기는 기기 목록에 자동으로 나타납니다.
  2. 다른 네트워크의 컴퓨터는 추가 카드에서 기기 추가를 눌러 주소를 입력합니다.
  3. 기기를 처음 선택하면 호스트에 접근을 요청합니다. 호스트에서 승인하세요.
  4. 다른 기기가 이미 연결되어 있으면 이어받을지 묻습니다. 이어받으면 그 기기의 연결이 끊어집니다.
  5. 다른 네트워크에 연결하려면 자체 VPN이나 Tailscale 네트워크처럼 두 기기가 서로 통신할 수 있는 경로가 필요합니다. 주소를 추가하는 것만으로는 경로가 만들어지지 않습니다.
  6. 기기 카드 메뉴의 주소 변경에는 주소를 한 줄에 하나씩 여러 개 입력할 수 있으며, 모두 페어링한 포트를 사용합니다. DeskPort는 이 주소들을 동시에 시도하고 응답한 주소 중 목록에서 가장 앞에 있는 것을 사용합니다. 따라서 LAN 주소를 맨 앞에, 도메인이나 VPN 주소를 그 뒤에 두세요. 연결 중에도 바꿀 수 있습니다. 열려 있는 세션은 현재 주소를 유지하고 다음 연결부터 새 목록을 사용합니다.
  7. Sunshine과 DeskPort 바인딩 기능이 없는 호스트는 기존 방식 호스트 추가와 PIN 페어링을 사용합니다. PIN을 승인할 수 있도록 호스트의 화면을 열어 두세요.
  8. 제어 권한을 철회하려면 공유하는 컴퓨터의 공유에서 저장된 접근 권한을 삭제하세요. 기기에서 카드를 삭제하는 것과 접근 권한을 철회하는 것은 별개의 작업입니다. 두 컴퓨터의 연결 관계를 해제할 때는 양방향의 권한을 모두 삭제하세요.

기기 목록 정리하기

  1. 상단 바의 편집으로 편집 모드에 들어가고 카드를 끌어 순서를 바꿉니다.
  2. 기기를 다른 기기 위에 놓으면 그룹이 됩니다. 휴대폰 홈 화면의 폴더와 같습니다.
  3. 카드 메뉴의 별칭 설정은 이 기기에서만 이름을 바꿉니다.
  4. 새로 고침은 저장된 기기를 다시 확인하고 새 기기를 찾습니다.
  5. 기기 카드 메뉴를 열면 상태와 주소를 확인하고 연결 작업을 할 수 있습니다. 주소 변경은 저장된 연결 정보를 업데이트합니다. 별칭을 설정해도 원격 컴퓨터 자체의 이름은 바뀌지 않습니다.

창과 백그라운드 세션

  1. 데스크톱에서는 뷰어를 닫거나 숨겨도 세션이 백그라운드에서 연결된 상태로 유지됩니다. 연결 끊기는 해당 연결을 끝내고, 종료는 DeskPort를 종료합니다.
  2. 트레이 메뉴나 기기 목록에서 연결 중인 데스크톱을 다시 불러올 수 있습니다. 세션이 여러 개이면 세션 메뉴에서 원하는 세션을 선택하세요.
  3. 뷰어를 숨기거나 다른 곳으로 포커스를 옮기면 원격에서 눌린 상태인 키와 버튼이 해제됩니다. 원격 세션의 연결을 유지하면서 로컬 컴퓨터를 사용할 수 있습니다.
  4. 세션을 새로 연결하거나 저장된 스트리밍 설정을 적용하려면 기기 메뉴에서 다시 연결을 사용하세요.

데스크톱 키보드 단축키

  1. Meta + '로 DeskPort를 표시하거나 숨깁니다. macOS에서는 Command + ', Windows에서는 Windows + ', Linux에서는 Super + '를 사용합니다. 키를 놓으면 실행됩니다. 선택한 세션을 다시 불러오며, 연결된 세션이 없으면 기기를 표시합니다.
  2. 설정 → 키보드 단축키 → 전역 창 단축키는 기본적으로 켜져 있습니다. 끄면 시스템의 키 할당이 해제되고 뷰어의 대체 처리도 즉시 비활성화됩니다. 이 선택은 이 컴퓨터에 저장됩니다.
  3. 설정 → 키보드 단축키에서 전역 창 단축키 행의 현재 키 조합을 클릭하세요. 키 조합을 누르거나 키 선택을 사용한 다음 저장하세요. 새 할당은 이 컴퓨터에 즉시 적용됩니다. 기본값 복원은 Meta + 아포스트로피(')(macOS에서는 Command + 아포스트로피)로 되돌립니다. 취소를 선택하면 이전 할당을 유지합니다. 키를 기록하는 동안 전역 단축키는 일시 중지됩니다.
  4. KDE Plasma는 일반적으로 Meta+1–9를 작업 관리자 항목에 할당합니다. 키 기록이 반응하지 않으면 키 선택으로 조합을 입력하세요. 저장할 때 데스크톱 환경에서 충돌 해결을 요청할 수 있으며, 다른 조합을 선택해도 됩니다.
  5. Wayland에서는 데스크톱 환경이 권한을 요청하고 키 할당을 선택하게 할 수 있습니다. 데스크톱 환경에서 선택한 단축키가 우선합니다. 등록이 거부되거나 지원되지 않거나 이미 사용 중이면 트레이나 기기 목록을 사용하세요. DeskPort는 다른 앱의 키 할당을 대체하지 않습니다.
  6. 데스크톱 연결 중 Ctrl+Alt+Shift+Z는 원격 입력을 해제하거나 다시 캡처하고, X는 전체 화면을 전환하며, N은 다음 연결된 데스크톱으로 전환합니다. 각 문자 키를 누를 때 Ctrl+Alt+Shift를 함께 누르세요.
  7. Ctrl+Alt+Shift+S는 스트리밍 통계 표시를 전환합니다. D는 뷰어를 최소화하고, M은 포인터 모드를 전환하며, C는 데스크톱 모드에서 로컬 포인터 표시를 전환하고, L은 포인터 이동 영역 제한을 전환합니다.
  8. Ctrl+Alt+Shift+V는 로컬 클립보드의 텍스트를 키보드로 입력하듯 전송합니다. Q는 먼저 전체 화면을 해제하며, 창 상태에서 Ctrl+Alt+Shift+Q를 다시 누르면 연결이 끊어집니다.

전체 화면

  1. 데스크톱에서는 기기 설정 → 고급 스트리밍 설정 → 연결 창에서 다음 연결에 사용할 창, 전체 화면, 테두리 없는 전체 화면을 선택합니다.
  2. 컴퓨터에서는 연결 중 Ctrl+Alt+Shift+X로 전체 화면을 켜고 끄며, 휴대폰이나 태블릿에서는 떠 있는 버튼을 다시 불러옵니다.
  3. 휴대폰과 태블릿에서는 원격 데스크톱이 항상 화면 전체를 씁니다. 떠 있는 버튼을 탭하면 키보드, 길게 누르면 메뉴가 열립니다.
  4. 호스트는 연결된 기기에 전체 화면 해제를 요청할 수 있지만 전체 화면을 강제하지는 않습니다.

화질과 가상 화면

  1. 원격 데스크톱은 창 크기를 따르므로 창 크기를 바꾸면 원격 데스크톱도 바뀝니다.
  2. 가상 화면은 연결 중 호스트 자체 화면을 어떻게 할지 정합니다.
  3. 데스크톱 미세 조정으로 원격 데스크톱의 모든 것을 크게 또는 작게 할 수 있습니다.
  4. 이 설정은 기기마다 따로 저장됩니다.
  5. 창에 맞추기는 뷰어에서 그릴 수 있는 픽셀 수를 사용합니다. 끄면 저장된 해상도를 대신 사용합니다. 사용할 수 있는 데스크톱 크기와 배율은 여전히 호스트에 따라 달라집니다.
  6. 데스크톱 미세 조정: 1.5는 조작 요소를 크게 하고, 0.5는 더 많은 내용을 표시합니다. 연결 중에 적용됩니다. 호스트의 최소 크기 제한으로 더 이상 확대할 수 없으면 창을 키우거나 전체 화면을 사용해 보세요.
  7. 기본 + 복제는 원격 작업 공간을 복제하고, 기본 화면만은 호스트의 다른 화면을 끄며, 확장은 작업 공간을 추가합니다. 지원 여부는 호스트에 따라 다릅니다. 세션이 끝나면 이전 화면 배치로 복원됩니다.

키보드, 포인터 및 클립보드

  1. 기기 설정 → 입력은 키보드, 포인터, 컨트롤러 동작을 전송할지 설정합니다. 보기만 하려면 끄세요. 수신하는 오디오는 소리에서 별도로 설정합니다.
  2. 고급 스트리밍 설정 → 키보드 및 포인터에는 포인터 모드, 스크롤 방향, 시스템 단축키 전달, 세션 클립보드 공유가 있습니다.
  3. Mac 호스트에서 Super / Windows는 Command에, Alt는 Option에 대응합니다. 운영 체제가 일부 단축키를 사용할 수 있습니다. Ctrl+Alt+Shift+Z로 입력 대상을 로컬 컴퓨터로 되돌리세요.
  4. 로컬 입력기 사용은 기본적으로 꺼져 있습니다. 기기별로 켜고 다시 연결하면 이 컴퓨터의 IME로 입력할 수 있습니다. 후보는 원격 커서 위치가 아닌 왼쪽 위 근처에 표시됩니다. 게임에서는 필요에 따라 원격 IME나 물리 키를 사용하세요.
  5. 세션 클립보드 공유는 양쪽 기기가 지원하는 경우 텍스트, 이미지, 파일을 지원합니다. 복사와 붙여넣기가 안 되면 세션 연결을 유지하고 양쪽에서 이 옵션을 확인하세요.
  6. 기기 스트리밍 설정 변경은 대부분 다시 연결한 뒤 적용됩니다. 데스크톱 미세 조정은 세션 중에 적용되며, 모양과 전역 창 단축키는 즉시 적용됩니다.

화질, 소리 및 데이터 사용량

  1. 고급 스트리밍 설정에서는 자동, 선명도 우선, 부드러움 우선, 데이터 절약, 사용자 정의 화질 모드를 제공합니다. 자동은 해상도에 따라 대역폭을 선택하고 네트워크 상태에 맞춰 조정합니다.
  2. 데이터 절약은 30 fps와 5 Mbps의 비디오 한도를 사용합니다. 상단 바의 데이터 세이버 스위치는 모든 기기에 적용됩니다. 오디오와 프로토콜 트래픽은 별도로 추가됩니다.
  3. 프레임 속도와 대역폭이 높을수록 더 많은 네트워크 용량과 처리 성능이 필요합니다. 움직임이 끊기거나 입력이 지연되면 이 값을 낮추고 스트리밍 통계를 확인한 뒤 화질을 높이세요.
  4. 소리 옵션에는 DeskPort가 포커스를 잃을 때 음소거하는 기능과 호스트에서도 소리를 재생하는 기능이 있습니다. 소리가 나지 않으면 기기의 소리 스위치, 포커스 해제 시 음소거 설정, 양쪽 컴퓨터의 오디오 출력을 확인하세요.

브라우저에서 연결하기

  1. 데스크톱 호스트에서 공유 → 브라우저 접근을 열고 다른 기기에서 표시된 URL을 스캔하거나 여세요. 연결하기 전에 공유를 시작하세요.
  2. 호스트나 인증 앱에 표시된 6자리 코드를 입력하세요. 코드는 30초마다 바뀝니다. 같은 Tailscale 계정으로 로그인했다고 인식된 기기는 코드 없이 연결할 수 있습니다.
  3. 연결하는 기기에서 호스트의 로컬 HTTPS 인증서를 신뢰해야 합니다. 신뢰하기 전에 URL과 인증서가 본인의 호스트와 일치하는지 확인하세요.
  4. 이 브라우저를 7일 동안 기억하세요를 켜면 해당 브라우저에서 이후 코드 입력을 건너뜁니다. 권한을 철회하려면 공유에서 페어링된 브라우저를 삭제하세요. 인증용 QR 코드는 비공개로 보관하세요. 비밀 키를 재설정하면 기존 인증 앱 설정은 무효화됩니다.

설정, 개인정보 보호 및 피드백

  1. 설정에서는 이 컴퓨터의 테마, 강조 색상, 언어, 상단 바 데이터 사용량 표시, 전역 창 단축키를 설정합니다. 기기 설정에서는 저장된 연결을 개별적으로 설정합니다.
  2. 진단 로그는 기본적으로 꺼져 있습니다. 문제를 재현하기 전에 설정 → 진단 및 피드백에서 켜세요. 직접 공유하기로 선택할 때까지 로그는 이 컴퓨터에만 보관됩니다.
  3. 문제 신고는 ZIP을 만들고 GitHub 이슈 초안을 엽니다. 자동으로 업로드하거나 제출하지 않습니다. 공개 이슈에 첨부하기 전에 압축 파일을 검토하고 재현 절차, 사용한 시스템, 예상 동작을 설명하세요.
  4. 진단을 끄면 새 기록이 중지됩니다. 저장된 진단 데이터 삭제는 기존 로그와 생성된 ZIP을 삭제합니다. 설정의 개인정보 보호와 라이선스에서 기록되는 데이터와 포함된 소프트웨어를 설명합니다.

문제가 생겼을 때

  1. 오프라인으로 보이는 기기는 대개 잠자기 상태이거나 다른 네트워크에 있거나 공유하지 않는 상태입니다.
  2. 상단 바의 새로 고침은 저장된 모든 기기를 다시 확인합니다.
  3. 설정의 문제 신고는 이슈에 첨부할 로그 압축 파일을 만듭니다. 공유하기 전에 내용을 확인하세요.
  4. 기기가 계속 오프라인이면 잠자기 상태가 아닌지, 공유가 켜져 있는지, 저장된 주소에 연결할 수 있는지 확인하세요. 다시 시도하기 전에 호스트의 준비 상태와 방화벽을 확인하세요. 새로 고침으로 모든 호스트를 깨우거나 네트워크 경로를 복구할 수는 없습니다.
  5. 화면이 검게 나오면 화면 기록 권한과 선택된 호스트 디스플레이를 확인하세요. 제어가 안 되면 손쉬운 사용 권한, 기기의 입력 스위치, 뷰어에 포커스가 있는지 확인하세요.
  6. 전역 창 단축키가 작동하지 않으면 설정의 해당 스위치, 데스크톱 환경의 단축키 권한, 다른 앱과의 충돌을 확인하세요. 껐다가 다시 켜면 등록을 다시 요청합니다. 트레이와 기기는 계속 사용할 수 있습니다.
