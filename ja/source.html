バージョンノート

ビルド 14 は、署名済みの SDK 修正をバージョン 1.5 として TestFlight と App Store 審査用に再パッケージしたものです。

ビルド 13（バージョン 1.3）は、ソースからビルドした OpenSSL XCFramework に署名し、アーカイブ時に SDK 由来の署名メタデータを検証します。App Store の処理と審査は別です。

ビルド 11 には、レスポンシブなデバイスカード、接続と入力の改善、ソースからビルドした OpenSSL と対応するデバッグシンボルが含まれます。完全なソースはリンク先のソース専用 GitHub リリースで配布しています。App Store の審査状況は別です。

ビルド 7 は、ビルド 6 を App Store リリース用にバージョン 1.1 として再パッケージしたもので、アプリの動作に変更はありません。

ビルド 6 では、デスクトップへの直接入室、デバイスごとのデスクトップ調整、確認付きの引き継ぎ（引き継がれた側のクライアントに具体的な説明を表示）を追加しました。

ビルド 5 では、共有ワークスペースのコアとデバイスごとの仮想画面ポリシーを追加し、厳密な機能ネゴシエーションと、小型デバイスでも読みやすい設定を導入しました。

ビルド 4 は、ネイティブ Sunshine のサービスを除外し、DeskPort の承認バインディングを維持し、既存のバインディングを削除せずに保存したドメイン／IP を編集できるようにしました。検出の通信方式は変わりません。

ビルド 3 は、オフラインで参照できる完全な依存関係の表示を追加し、既に使用している OpenSSL パッケージのバージョンを固定しました。接続インターフェースはビルド 2 から変わりません。ビルド 2 では、上流の自動パブリックアドレス検出を削除しました。ビルド 1 のソースは、最初の TestFlight ビルドの受領者向けに引き続き提供しています。

保証は一切ありません。Apple SDK と署名用の認証情報はビルドする人が用意してください。DeskPort は第三者のメディアカタログやサブスクリプションコンテンツへのアクセスを提供しません。アクセス権のあるコンピュータとコンテンツのみを使用してください。

ソースのダウンロードに関する問題は GitHub Issues で報告してください。認証情報や個人的な内容は投稿しないでください。
