Notes de version

Le build 14 réempaquette la correction signée du SDK en version 1.5 pour TestFlight et l’examen App Store.

Le build 13 (version 1.3) signe le XCFramework OpenSSL compilé depuis les sources et vérifie lors de l’archivage les métadonnées de signature d’origine du SDK. Le traitement et l’examen App Store sont distincts.

Le build 11 inclut des cartes d’appareil adaptatives, des améliorations de connexion et de saisie, ainsi qu’OpenSSL compilé depuis les sources avec les symboles de débogage correspondants. Son code source complet est hébergé dans la release GitHub liée, contenant uniquement les sources ; le statut d’examen App Store est distinct.

Le build 7 réempaquette le build 6 en version 1.1 pour la publication sur l’App Store, sans changement de comportement de l’app.

Le build 6 ajoute l’accès direct au bureau, le réglage du bureau par appareil et la reprise de session confirmée, avec une explication précise sur le client évincé.

Le build 5 ajoute le noyau d’espace de travail partagé et des règles d’écran virtuel par appareil, avec une négociation stricte des capacités et des réglages lisibles sur les appareils compacts.

Le build 4 filtre les services Sunshine natifs, conserve la liaison d’approbation DeskPort et permet de modifier les domaines/IP enregistrés sans supprimer les liaisons existantes. Le transport de découverte est inchangé.

Le build 3 ajoute les mentions complètes des dépendances hors ligne et fige la version du paquet OpenSSL déjà utilisée. L’interface de connexion est inchangée depuis le build 2. Le build 2 a supprimé la découverte automatique de l’adresse publique héritée du projet amont. Le code source du build 1 reste disponible pour les destinataires du premier build TestFlight.

Aucune garantie n’est fournie. Les SDK Apple et les identifiants de signature sont fournis par la personne qui compile. DeskPort ne fournit aucun catalogue multimédia tiers ni accès à des contenus par abonnement ; n’utilisez que des ordinateurs et contenus auxquels vous êtes autorisé à accéder.

Problèmes de téléchargement des sources : signalez-les via GitHub Issues. Ne publiez pas d’identifiants ni de contenus privés.
