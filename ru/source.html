Примечания к версиям

Сборка 14 переупаковывает подписанное исправление SDK как версию 1.5 для TestFlight и проверки в App Store.

Сборка 13 (версия 1.3) подписывает собранный из исходников OpenSSL XCFramework и проверяет при архивации метаданные подписи происхождения SDK. Обработка и проверка в App Store выполняются отдельно.

Сборка 11 включает адаптивные карточки устройств, улучшения подключения и ввода, а также собранный из исходников OpenSSL с соответствующими отладочными символами. Полный исходный код размещён в связанном релизе GitHub, содержащем только исходники; статус проверки в App Store — отдельный.

Сборка 7 переупаковывает сборку 6 как версию 1.1 для выпуска в App Store без изменений в поведении приложения.

Сборка 6 добавляет прямой вход на рабочий стол, настройку рабочего стола для каждого устройства и перехват сеанса с подтверждением и конкретным пояснением на вытесненном клиенте.

Сборка 5 добавляет ядро общего рабочего пространства и политики виртуального экрана для каждого устройства, со строгим согласованием возможностей и удобочитаемыми настройками на компактных устройствах.

Сборка 4 отфильтровывает нативные службы Sunshine, сохраняет привязку подтверждения DeskPort и позволяет редактировать сохранённые домены/IP без удаления существующих привязок. Транспорт обнаружения не изменён.

Сборка 3 добавляет полные офлайн-уведомления о зависимостях и фиксирует уже используемую версию пакета OpenSSL. Интерфейс подключения не изменился по сравнению со сборкой 2. Сборка 2 убрала автоматическое определение публичного адреса из исходного проекта. Исходный код сборки 1 остаётся доступным для получателей первой сборки TestFlight.

Никаких гарантий не предоставляется. Apple SDK и учётные данные для подписи предоставляет тот, кто выполняет сборку. DeskPort не предоставляет сторонних медиакаталогов или доступа к контенту по подписке; используйте только компьютеры и контент, к которым у вас есть право доступа.

Проблемы с загрузкой исходного кода: сообщите через GitHub Issues. Не публикуйте учётные данные или личную информацию.
