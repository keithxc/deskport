Connection help · 连接帮助

Connect your desktop

1. Install and open DeskPort on your computer. Enable Sharing. Keep the computer awake and initially connect both devices to the same local network. 2. Allow Local Network access on your iPad/iPhone. Select the computer card, or add its reachable address manually. 3. Approve the client on the computer. For legacy PIN pairing, use DeskPort → Sharing → Compatibility & diagnostics → Legacy PIN pairing. With Sunshine, use its web interface. Keep the client PIN dialog open until approval completes. 4. Select the paired computer. The client opens its Desktop entry. The host must expose Desktop; another running application may need to be closed by its owner first.

Touch and keyboard Tap to click; double-tap to open; drag with one finger; scroll with two fingers; long-press or two-finger tap to right-click. Use the bottom keyboard button to type. Per-device settings offer a Trackpad alternative. The menu includes Disconnect; closing the client session does not shut down the computer.

Cannot find or connect? Check local-network permission in iPadOS Settings, host Sharing, the firewall, and that both devices can reach each other. Guest Wi-Fi can isolate devices. Same-name cards can represent independent DeskPort and Sunshine services: compare the displayed address and port. Do not expose host ports to the internet as a troubleshooting shortcut; use a network you control.
