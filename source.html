Version notes

Build 11 includes responsive device cards, connection and input refinements, and source-built OpenSSL with matching debug symbols. Its complete source download is hosted in the linked source-only GitHub release; App Store review status is separate.

Build 7 repackages build 6 as version 1.1 for App Store release, with no application behavior changes.

Build 6 adds direct desktop entry, per-device desktop tuning and confirmed takeover with a specific explanation on the displaced client.

Build 5 adds the shared workspace core and per-device virtual-screen policies, with strict capability negotiation and readable compact-device settings.

Build 4 filters native Sunshine services, keeps DeskPort approval binding, and adds saved domain/IP editing without removing existing bindings. Discovery transport is unchanged.

Build 3 adds complete offline dependency notices and pins the already-used OpenSSL package version. The connection interface is unchanged from build 2. Build 2 removed upstream automatic public-address discovery. Build 1 source remains available for recipients of the initial TestFlight build.
