Desktop Anda, di iPad Anda.

Gunakan komputer Anda sendiri dari iPad atau iPhone dengan kontrol sentuh, papan ketik, dan penunjuk. DeskPort menghadirkan aplikasi desktop dan ruang kerja Anda ke layar perangkat seluler Anda.

Mulai dengan DeskPort di komputer Anda

Aplikasi desktop ini gratis dan bersumber terbuka. Instal paket DeskPort yang mendukung fungsi host di komputer Anda, aktifkan Membagikan, lalu hubungkan menggunakan aplikasi iPad/iPhone.

Unduh DeskPort 0.7.3 untuk komputer Anda di GitHub →
macOS Apple Silicon · Linux x86_64 · Windows x64 — penampil dan host. Flatpak Linux hanya berfungsi sebagai penampil. Klien Android dalam pengujian tertutup (detail).

Dirancang untuk pekerjaan desktop

  • Komputer tersimpan dengan preferensi gambar, audio, dan input tersendiri.
  • Mode Sentuhan langsung atau papan jejak, serta papan ketik di layar dengan tombol pengubah dan navigasi.
  • Tampilan potret dan lanskap, dengan opsi ukuran desktop yang didukung oleh host DeskPort Anda.
  • Progres koneksi, kontrol sesi, dan konfirmasi sebelum mengambil alih sesi yang sedang aktif.

Aplikasi iPad/iPhone memerlukan host desktop DeskPort. Host Sunshine mandiri yang tidak dimodifikasi tidak didukung. Tidak ada akun DeskPort atau komputer cloud yang disertakan. Fitur tampilan dan input yang tersedia bergantung pada komputer, paket host, dan perangkat yang terhubung.
