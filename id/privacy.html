Kebijakan privasi

Terjemahan ini disediakan hanya sebagai referensi. Jika terdapat perbedaan, versi bahasa Inggris yang berlaku.

DeskPort untuk iPhone, iPad, dan Android — Kebijakan Privasi Aplikasi Android sedang dalam pengujian tertutup Google Play dan belum tersedia secara publik. Berlaku efektif: 2026-09-28

DeskPort adalah klien desktop jarak jauh. Aplikasi ini terhubung ke komputer yang Anda otorisasi. Aplikasi ini tidak memerlukan akun DeskPort serta tidak mengandung SDK periklanan atau analitik.

Sesi jarak jauh Host mengirimkan gambar layar, audio, dan informasi koneksi ke perangkat Anda. Perangkat Anda mengirimkan input papan ketik, penunjuk, dan sentuhan ke host. Data tersebut diproses untuk menjalankan sesi; DeskPort tidak mengunggah konten sesi ke server yang dioperasikan pengembang. Hanya hubungkan ke host yang Anda percayai. Keamanan jaringan bergantung pada host, protokol, dan konfigurasi jaringan; tidak setiap koneksi atau saluran media dijamin terenkripsi.

Data yang disimpan di perangkat Anda Nama host tersimpan, alamat, kredensial pemasangan/pengikatan, sertifikat, dan preferensi disimpan secara lokal. Saat persetujuan perangkat, pengidentifikasi klien yang dibuat aplikasi, nama/model perangkat, dan detail koneksi dikirim ke komputer yang Anda pilih; komputer tersebut menyimpan catatan otorisasinya. Pengidentifikasi ini bukan pengidentifikasi periklanan dan tidak dikirim ke layanan yang dioperasikan pengembang. Hapus host tersimpan dari Perangkat untuk menghapus koneksi tersimpannya. Menghapus host tidak mencabut otorisasi pada komputer tersebut: cabut juga klien di pengaturan host. Menghapus aplikasi akan menghapus data wadah aplikasinya. Aplikasi Android mengecualikan semua datanya dari pencadangan cloud dan transfer antarperangkat, sehingga host dan kredensial yang disimpan tidak pernah berpindah ke ponsel lain; pencadangan sistem operasi Apple dikelola oleh sistem. Data yang sudah ada di host dikelola secara terpisah.

Penemuan jaringan dan pihak ketiga Izin jaringan lokal memungkinkan penemuan host dan koneksi. Versi Apple dan Android saat ini tidak meminta layanan pihak ketiga untuk menemukan alamat IP publik Anda. Anda dapat terhubung menggunakan host yang ditemukan secara lokal atau alamat yang Anda masukkan. Alamat yang sudah tersimpan tetap dipertahankan; hapus host untuk menghapus koneksi tersimpannya. Penyedia jaringan dan host yang diotorisasi memproses lalu lintas koneksi. Build TestFlight 1.0 (1) terdahulu mungkin menghubungi stun.moonlight-stream.org untuk penemuan IPv4 publik.

Izin Apple: izin Jaringan Lokal memungkinkan penemuan host dan koneksi; Bluetooth mendukung mouse opsional Citrix X1. Papan ketik dan mouse standar menggunakan dukungan input sistem. Android: internet dan status jaringan/Wi-Fi mendukung penemuan dan koneksi; kunci layar menyala (wake lock) menjaga layar dan koneksi tetap aktif selama sesi; getaran memberikan umpan balik getar kontroler dan sentuhan; penangkapan papan ketik mengirimkan kombinasi tombol sistem ke host saat Anda terhubung. Integrasi Android TV dapat menyimpan entri peluncur lokal. Kedua klien tidak meminta akses ke perpustakaan foto, mikrofon, kontak, atau lokasi.

Diagnostik dan dukungan Aplikasi dapat menulis diagnostik koneksi teknis secara lokal. Apple atau Google dapat menyediakan laporan kerusakan dan kinerja sesuai dengan platform mereka dan pengaturan perangkat Anda. DeskPort tidak menyertakan SDK analitik atau pelaporan kerusakan pihak ketiga. Jika Anda menghubungi dukungan, informasi yang Anda pilih untuk dikirim digunakan untuk menyelidiki permintaan Anda. Jangan memublikasikan kata sandi, token pemasangan, alamat publik/privat, tangkapan layar pribadi, atau informasi pemberi kerja di laporan publik.
